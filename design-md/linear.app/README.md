# Linear 风格设计系统

[DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/linear.app/DESIGN.md) 提取自公开的 [linear](https://linear.app/) 网站。这不是官方设计系统。颜色、字体和间距可能并非 100% 准确，但它是构建类似产品的良好起点。

## 文件

| 文件 | 说明 |
|------|------|
| `DESIGN.md` | 完整的设计系统文档（9 个章节） |
| `preview.html` | 交互式设计令牌目录（亮色模式） |
| `preview-dark.html` | 交互式设计令牌目录（暗色模式） |


使用 [DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/linear.app/DESIGN.md) 作为参考，供 AI 智能体（Claude、Cursor、Stitch）生成符合 Linear 设计语言的 UI。
