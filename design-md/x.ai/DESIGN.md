# 设计系统：xAI

## 1. 视觉主题与氛围

xAI 的网站是深色优先、等宽字体驱动的野蛮主义极简主义的大师级作品——这一设计系统感觉像是由那些懂得克制是终极 sophistication 形式的工程师构建的。整个体验锚定在近乎黑色的背景 (`#1f2228`) 与纯白文本 (`#ffffff`) 上，创造出高对比度、终端启发的美学，传递出深厚的技术可信度。没有渐变、没有装饰性插图、没有色彩点缀相互竞争。这是一个通过缺席来沟通的网站。

字体系统在两种精心选择的字体之间分割。`GeistMono`（Vercel 的等宽字体）以惊人的 320px 尺寸和 300 粗细处理展示级标题，同时也作为按钮字体，采用大写字母和扩展的字间距 (1.4px)。`universalSans` 以干净、几何化的无衬线风格处理所有正文和次级标题文本。等宽字体作为展示字体的选择是定义性的美学决策——它将 xAI 定位为基础设施而非消费产品，作为某些由生活在终端中的人构建的东西。

间距系统基于 8px 基网格运行，值集中在较小的一端 (4px、8px、24px、48px)，反映出密集的、信息聚焦的布局理念。边框圆角最小化——网站几乎不圆角化任何内容，保持锐利的建筑边缘。没有装饰性阴影、没有渐变、没有分层海拔。深度纯粹通过对比和留白传达。

**关键特征：**
- 纯深色主题：`#1f2228` 背景配 `#ffffff` 文本——没有灰色中间地带
- GeistMono 以极端展示尺寸 (320px, weight 300)——等宽字体即奢华
- 大写等宽按钮配 1.4px 字间距——技术化、命令式
- universalSans 用于正文 16px/1.5 和标题 30px/1.2——干净的对比
- 零装饰元素：无阴影、无渐变、无彩色点缀
- 8px 间距网格，稀疏而刻意的比例
- Heroicons SVG 图标系统——极简、功能化
- Tailwind CSS 配合任意值——实用优先的工程方法

## 2. 调色板与角色

### 主色
- **纯白** (`#ffffff`)：唯一的文本颜色、链接颜色和所有前景元素。在 xAI 的系统中，白色不是背景——它是声音。
- **深色背景** (`#1f2228`)：画布。一种带有微妙蓝色底色的暖调近黑色（不是纯黑，不是中性灰）。这种特定色调防止了 `#000000` 的刺眼眼疲劳，同时保持深度黑暗。

### 交互
- **白色默认** (`#ffffff`)：默认状态下链接和交互元素的颜色。
- **白色弱化** (`rgba(255, 255, 255, 0.5)`): 链接的悬停状态——一种刻意的变暗而非变亮，这不寻常且独特。
- **白色微妙** (`rgba(255, 255, 255, 0.2)`): 边框、分割线和微妙的表面修饰。
- **Ring Blue** (`rgb(59, 130, 246) / 0.5`): Tailwind 的默认焦点环颜色 (`--tw-ring-color`)，用于键盘辅助功能的焦点状态。

### 表面与边框
- **表面提升** (`rgba(255, 255, 255, 0.05)`): 微妙的卡片背景和悬停表面——几乎不可见的提升。
- **表面悬停** (`rgba(255, 255, 255, 0.08)`): 交互容器的稍更可见的悬停状态。
- **边框默认** (`rgba(255, 255, 255, 0.1)`): 卡片、分割线和容器的标准边框。
- **边框强化** (`rgba(255, 255, 255, 0.2)`): 强调边框用于活动状态和按钮轮廓。

### 功能
- **文本主色** (`#ffffff`): 所有标题、正文文本、标签。
- **文本次级** (`rgba(255, 255, 255, 0.7)`): 描述、说明文字、支持文本。
- **文本第三级** (`rgba(255, 255, 255, 0.5)`): 弱化的标签、占位符文本、时间戳。
- **文本第四级** (`rgba(255, 255, 255, 0.3)`): 禁用文本、非常微妙的注释。

## 3. 字体排印规则

### 字体系列
- **展示/按钮**: `GeistMono`, 降级：`ui-monospace, SFMono-Regular, Roboto Mono, Menlo, Monaco, Liberation Mono, DejaVu Sans Mono, Courier New`
- **正文/标题**: `universalSans`, 降级：`universalSans Fallback`

### 层级

| 角色 | 字体 | 尺寸 | 粗细 | 行高 | 字间距 | 转换 | 备注 |
|------|------|------|------|------|--------|------|------|
| 展示主标题 | GeistMono | 320px (20rem) | 300 | 1.50 | normal | none | 极端比例，等宽奢华 |
| 章节标题 | universalSans | 30px (1.88rem) | 400 | 1.20 (tight) | normal | none | 干净的无衬线对比 |
| 正文 | universalSans | 16px (1rem) | 400 | 1.50 | normal | none | 标准阅读文本 |
| 按钮 | GeistMono | 14px (0.88rem) | 400 | 1.43 | 1.4px | uppercase | 跟踪等宽，命令式 |
| 标签/说明 | universalSans | 14px (0.88rem) | 400 | 1.50 | normal | none | 支持文本 |
| 小字/元数据 | universalSans | 12px (0.75rem) | 400 | 1.50 | normal | none | 时间戳、脚注 |

### 原则
- **等宽作为展示**: GeistMono 在 320px 不是噱头——它是品牌声明。固定宽度字符在极端比例下创造出节奏化、建筑化的品质，任何比例字体都无法实现。
- **大比例下轻量**: 320px 标题使用 300 粗细，防止等宽字体在极端尺寸下显得沉重或粗野。它读起来精确，而非压倒性。
- **大写按钮**: 所有按钮文本都是大写 GeistMono 配 1.4px 字间距。这创造出独特的技术化、近乎命令行美学的交互元素。
- **无衬线用于阅读**: universalSans 在 16px/1.5 为正文内容提供出色的可读性，与等宽展示元素形成干净对比。
- **双字体清晰**: 系统仅使用两种字体，角色明确——等宽用于冲击和交互，无衬线用于信息和阅读。无重叠，无歧义。

## 4. 组件样式

### 按钮

**主按钮 (深色上的白色)**
- 背景：`#ffffff`
- 文本：`#1f2228`
- 内边距：12px 24px
- 圆角：0px (锐利边角)
- 字体：GeistMono 14px weight 400, 大写，字间距 1.4px
- 悬停：`rgba(255, 255, 255, 0.9)` 背景
- 用途：主 CTA ("TRY GROK", "GET STARTED")

**幽灵/轮廓**
- 背景：透明
- 文本：`#ffffff`
- 内边距：12px 24px
- 圆角：0px
- 边框：`1px solid rgba(255, 255, 255, 0.2)`
- 字体：GeistMono 14px weight 400, 大写，字间距 1.4px
- 悬停：`rgba(255, 255, 255, 0.05)` 背景
- 用途：次要操作 ("LEARN MORE", "VIEW API")

**文本链接**
- 背景：无
- 文本：`#ffffff`
- 字体：universalSans 16px weight 400
- 悬停：`rgba(255, 255, 255, 0.5)`——悬停时变暗
- 用途：内联链接、导航项

### 卡片与容器
- 背景：`rgba(255, 255, 255, 0.03)` 或透明
- 边框：`1px solid rgba(255, 255, 255, 0.1)`
- 圆角：0px (锐利) 或 4px (微妙)
- 阴影：无——xAI 不使用盒子阴影
- 悬停：边框切换为 `rgba(255, 255, 255, 0.2)`

### 导航
- 深色背景匹配页面 (`#1f2228`)
- 品牌标识：白色文本，左对齐
- 链接：universalSans 14px weight 400, `#ffffff` 文本
- 悬停：`rgba(255, 255, 255, 0.5)` 文本颜色
- CTA：白色主按钮，右对齐
- 移动端：汉堡包切换按钮

### 徽章/标签
**等宽标签**
- 背景：透明
- 文本：`#ffffff`
- 内边距：4px 8px
- 边框：`1px solid rgba(255, 255, 255, 0.2)`
- 圆角：0px
- 字体：GeistMono 12px 大写，字间距 1px

### 输入与表单
- 背景：透明或 `rgba(255, 255, 255, 0.05)`
- 边框：`1px solid rgba(255, 255, 255, 0.2)`
- 圆角：0px
- 焦点：环配 `rgb(59, 130, 246) / 0.5`
- 文本：`#ffffff`
- 占位符：`rgba(255, 255, 255, 0.3)`
- 标签：`rgba(255, 255, 255, 0.7)`, universalSans 14px

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 比例：4px, 8px, 24px, 48px
- 比例刻意稀疏——xAI 避免细粒度的间距区分，偏好通过留白本身创造清晰视觉层级的大跳跃

### 网格与容器
- 最大内容宽度：约 1200px
- 主视觉：全视口高度配巨大居中等宽标题
- 特性章节：简单的垂直堆叠配 generous 章节内边距 (48px-96px)
- 桌面端特性描述采用双列布局
- 全宽深色章节在整个页面保持单一深色背景

### 留白理念
- **极端慷慨**: xAI 使用大量的留白。320px 标题配 48px+ 周围内边距创造出一种空旷感，这本身就是一种设计声明——内容如此重要，需要空间呼吸。
- **垂直节奏优于水平密度**: 内容垂直堆叠，章节间有大间隙，而非水平填充。这创造出感觉刻意和电影感的滚动驱动体验。
- **无视觉噪音**: 装饰元素、章节间边框和颜色变化的缺席意味着留白是主要的结构工具。

### 断点
- 2000px, 1536px, 1280px, 1024px, 1000px, 768px, 640px
- Tailwind 响应式修饰符驱动断点行为

### 边框圆角比例
- 锐利 (0px): 按钮、卡片、输入的主要处理——默认
- 微妙 (4px): 次要容器上的偶尔柔化
- 近乎零圆角理念是品牌野蛮主义身份的核心

## 6. 深度与海拔

| 等级 | 处理 | 用途 |
|------|------|------|
| 平面 (Level 0) | 无阴影，无边框 | 页面背景，正文内容 |
| 表面 (Level 1) | `rgba(255,255,255,0.03)` 背景 | 微妙卡片表面 |
| 边框 (Level 2) | `1px solid rgba(255,255,255,0.1)` 边框 | 卡片、容器、分割线 |
| 活动 (Level 3) | `1px solid rgba(255,255,255,0.2)` 边框 | 悬停状态、活动元素 |
| 焦点 (辅助功能) | `ring` 配 `rgb(59,130,246)/0.5` | 键盘焦点指示器 |

**海拔理念**: xAI 完全拒绝了传统的基于阴影的海拔系统。网站上没有任何地方使用盒子阴影。相反，深度通过三种机制传达：(1) 基于不透明度的边框在交互时变亮，创造元素"激活"而非提升的感觉；(2) 极其微妙的背景不透明度变化 (`0.03` 到 `0.08`) 创造几乎不可察觉的表面区分；(3) 320px 展示字体和 16px 正文文本之间的巨大比例对比，创造字体深度。这是通过对比和不透明度实现的海拔，而非通过模拟光影。

## 7. 该做与不该做

### 该做
- 使用 `#1f2228` 作为通用背景——永远不要纯黑 `#000000`
- 对所有展示标题和按钮文本使用 GeistMono——等宽字体即品牌
- 对所有按钮标签应用大写 + 1.4px 字间距
- 对巨大展示标题 (320px) 使用 300 粗细
- 保持边框在 `rgba(255, 255, 255, 0.1)`——几乎不可见，非不存在
- 悬停时将交互元素变暗到 `rgba(255, 255, 255, 0.5)`——与惯例相反
- 保持锐利边角 (0px 圆角) 作为默认——野蛮主义精度
- 对所有正文和阅读文本使用 universalSans，16px/1.5

### 不该做
- 不要使用盒子阴影——xAI 零阴影海拔
- 不要引入超出白色和深色背景的色彩点缀——单色调色板是神圣的
- 不要使用大圆角 (8px+，药丸形状)——锐利边缘是刻意的
- 不要对标题使用粗体 (600-700)——仅 300-400 粗细
- 不要在悬停时提亮元素——xAI 改为变暗到 `0.5` 不透明度
- 不要添加装饰性渐变、插图或色块
- 不要对按钮使用比例字体——GeistMono 大写是强制性的
- 不要使用彩色状态指示器，除非绝对必要——保持在白/暗光谱内

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|------|------|
| 移动端 | <640px | 单列，主标题显著缩小 |
| 小平板 | 640-768px | 内边距略微增加 |
| 平板 | 768-1024px | 双列布局开始，标题尺寸增加 |
| 桌面 | 1024-1280px | 完整布局，慷慨的留白 |
| 大尺寸 | 1280-1536px | 更宽容器，更多呼吸空间 |
| 超大 | 1536-2000px | 最大内容宽度，居中 |
| 超超 | >2000px | 内容保持居中，极端边距 |

### 触摸目标
- 按钮使用 12px 24px 内边距实现舒适的触摸
- 导航链接间隔 24px 间隙
- 最小点击目标：44px 高度
- 移动端：全宽按钮便于拇指操作

### 折叠策略
- 主视觉：320px 等宽标题显著缩小（移动端约 48px-64px）
- 导航：水平链接折叠为汉堡包菜单
- 特性章节：双列转单列堆叠
- 章节内边距：96px -> 48px -> 24px 跨越断点
- 巨大展示字体是第一个调整大小的——它必须保持冲击力但不溢出

### 图像行为
- 极小化图像——网站依赖字体排印和留白
- 任何产品截图保持锐利边角
- 全宽媒体随视口按比例缩放

- 背景：深色 (`#1f2228`)

- 文本弱化：白色 50% (`rgba(255, 255, 255, 0.5)`)

- 边框默认：白色 10% (`rgba(255, 255, 255, 0.1)`)
- 边框强化：白色 20% (`rgba(255, 255, 255, 0.2)`)
- 表面微妙：白色 3% (`rgba(255, 255, 255, 0.03)`)

### 迭代指南
1. 始终以 `#1f2228` 背景开始——永远不要使用纯黑或灰色背景
2. GeistMono 用于展示和按钮，universalSans 用于其他所有——永远不要混淆这些角色
3. 所有按钮必须是 GeistMono 大写配 1.4px 字间距——这是不可协商的
4. 无阴影，永远——深度仅来自边框不透明度和背景不透明度
5. 边框始终是白色低不透明度 (默认 0.1，强调 0.2)
6. 悬停行为变暗到 0.5 不透明度而非提亮——与大多数系统相反
7. 默认锐利边角 (0px)——仅对特定次要容器使用 4px
8. 正文 16px universalSans 配 1.5 行高实现舒适阅读
9. 慷慨的章节内边距 (48px-96px)——让内容在黑暗中呼吸
10. 单色白 - 暗调色板是绝对的——抵制添加颜色，除非功能关键
