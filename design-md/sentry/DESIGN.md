# 设计系统：Sentry

## 1. 视觉主题与氛围

Sentry 的网站是一个以深色模式为主的开发者工具界面，采用代码编辑器和终端窗口的语言风格。整体美学植根于深紫黑色背景（`#1f1633`、`#150f23`），唤起 Sentry 为之打造的深夜调试场景。在这墨色画布上，精心策划的紫色、粉色和独特的青柠绿强调色（`#c2ef4e`）创造出既技术感十足又充满活力的视觉系统。

字体搭配经过深思熟虑："Dammit Sans" 作为展示字体出现在主体比例（88px，字重 700），其个性和态度与 Sentry 不羁的品牌声音相匹配（"代码会出错。更快修复它。"），而 Rubik 作为主力 UI 字体用于所有功能文本——标题、正文、按钮、说明和导航。Monaco 提供等宽字体层用于代码片段和技术内容，完成开发者工具三要素。

Sentry 的独特之处在于它对"深色 IDE"美学的拥抱，同时不失温暖而非冰冷刻板。温暖的紫色调取代了开发者工具典型的冷灰色，大胆的插图元素（3D 角色、多彩的产品截图）点缀在深色画布上。按钮系统使用标志性的柔和紫色（`#79628c`）配合内阴影，创造出触觉般的、几乎是物理的质感——按钮感觉像是可以按入表面。

**关键特征：**
- 深紫黑色背景（`#1f1633`、`#150f23`）—— 永不使用纯黑
- 温暖紫色强调色光谱：从深（`#362d59`）到中（`#79628c`、`#6a5fc1`）再到鲜艳（`#422082`）
- 青柠绿强调色（`#c2ef4e`）用于高可见度的 CTA 和高亮
- 粉色/珊瑚强调色（`#ffb287`、`#fa7faa`）用于焦点状态和次要高亮
- "Dammit Sans" 展示字体用于主体比例的品牌个性
- Rubik 作为主要 UI 字体，大写字母带字间距的标签
- Monaco 等宽字体用于代码元素
- 按钮上的内阴影创造触觉深度
- 磨砂玻璃效果使用 `blur(18px) saturate(180%)`

## 2. 调色板与角色

### 主品牌色
- **深紫色**（`#1f1633`）：主要背景，品牌的定义色
- **更深紫色**（`#150f23`）：更深的区域、页脚、次要背景
- **边框紫**（`#362d59`）：边框、分割线、微妙的结构线

### 强调色
- **Sentry 紫**（`#6a5fc1`）：主要交互色 —— 链接、悬停状态、焦点环
- **柔和紫**（`#79628c`）：按钮背景、次要交互元素
- **深紫罗兰**（`#422082`）：选择下拉框、激活状态、高强调表面
- **青柠绿**（`#c2ef4e`）：高可见度强调色、特殊链接、徽章高亮
- **珊瑚色**（`#ffb287`）：焦点状态背景、温暖强调色
- **粉色**（`#fa7faa`）：焦点轮廓、装饰强调色

### 文本色
- **纯白**（`#ffffff`）：深色背景上的主要文本
- **浅灰**（`#e5e7eb`）：次要文本、淡化内容
- **代码黄**（`#dcdcaa`）：语法高亮、代码标记

### 表面与覆盖层
- **玻璃白**（`rgba(255, 255, 255, 0.18)`）：磨砂玻璃按钮背景
- **玻璃暗**（`rgba(54, 22, 107, 0.14)`）：玻璃元素上的悬停覆盖层
- **输入白**（`#ffffff`）：表单输入背景（浅色上下文）
- **输入边框**（`#cfcfdb`）：表单字段边框

### 阴影
- **环境光晕**（`rgba(22, 15, 36, 0.9) 0px 4px 4px 9px`）：深紫色环境阴影
- **按钮悬停**（`rgba(0, 0, 0, 0.18) 0px 0.5rem 1.5rem`）：提升的悬停状态
- **卡片阴影**（`rgba(0, 0, 0, 0.1) 0px 10px 15px -3px`）：标准卡片海拔
- **内嵌按钮**（`rgba(0, 0, 0, 0.1) 0px 1px 3px 0px inset`）：触觉按压效果

## 3. 排版规则

### 字体系列
- **展示**：`Dammit Sans` —— 用于主标题的品牌个性字体
- **主要 UI**：`Rubik`，回退字体：`-apple-system, system-ui, Segoe UI, Helvetica, Arial`
- **等宽**：`Monaco`，回退字体：`Menlo, Ubuntu Mono`

### 层级

| 角色 | 字体 | 字号 | 字重 | 行高 | 字间距 | 说明 |
|------|------|------|--------|-------------|----------------|-------|
| 展示主标题 | Dammit Sans | 88px (5.50rem) | 700 | 1.20 (紧凑) | normal | 最大冲击力，品牌声音 |
| 展示次标题 | Dammit Sans | 60px (3.75rem) | 500 | 1.10 (紧凑) | normal | 次级主标题文本 |
| 区块标题 | Rubik | 30px (1.88rem) | 400 | 1.20 (紧凑) | normal | 主要区块标题 |
| 副标题 | Rubik | 27px (1.69rem) | 500 | 1.25 (紧凑) | normal | 功能区块标题 |
| 卡片标题 | Rubik | 24px (1.50rem) | 500 | 1.25 (紧凑) | normal | 卡片和区块标题 |
| 功能标题 | Rubik | 20px (1.25rem) | 600 | 1.25 (紧凑) | normal | 强调的功能名称 |
| 正文 | Rubik | 16px (1.00rem) | 400 | 1.50 | normal | 标准正文文本 |
| 正文强调 | Rubik | 16px (1.00rem) | 500–600 | 1.50 | normal | 加粗正文、导航项 |
| 导航标签 | Rubik | 15px (0.94rem) | 500 | 1.40 | normal | 导航链接 |
| 大写标签 | Rubik | 15px (0.94rem) | 500 | 1.25 (紧凑) | normal | `text-transform: uppercase` |
| 按钮文本 | Rubik | 14px (0.88rem) | 500–700 | 1.14–1.29 (紧凑) | 0.2px | `text-transform: uppercase` |
| 说明 | Rubik | 14px (0.88rem) | 500–700 | 1.00–1.43 | 0.2px | 通常大写 |
| 小说明 | Rubik | 12px (0.75rem) | 600 | 2.00 (宽松) | normal | 微妙的注释 |
| 微标签 | Rubik | 10px (0.63rem) | 600 | 1.80 (宽松) | 0.25px | `text-transform: uppercase` |
| 代码 | Monaco | 16px (1.00rem) | 400–700 | 1.50 | normal | 代码块、技术文本 |

### 原则
- **双重个性**：Dammit Sans 在展示比例上带来不羁的品牌特色；Rubik 为所有功能内容提供干净的专业感。
- **大写作为系统**：按钮、说明、标签和微文本都使用 `text-transform: uppercase` 配合微妙的字间距（0.2px–0.25px），在整个系统中创造系统化的"技术标签"模式。
- **字重分层**：Rubik 使用 400（正文）、500（强调/导航）、600（标题/强）、700（按钮/CTA）—— 干净的四层字重系统。
- **紧凑标题，宽松正文**：所有标题使用 1.10–1.25 行高；正文使用 1.50；小说明扩展到 2.00 以在极小字号下提高可读性。

## 4. 组件样式

### 按钮

**主柔和紫**
- 背景：`#79628c` (rgb(121, 98, 140))
- 文本：`#ffffff`，大写，14px，字重 500–700，字间距 0.2px
- 边框：`1px solid #584674`
- 圆角：13px
- 阴影：`rgba(0, 0, 0, 0.1) 0px 1px 3px 0px inset`（触觉内嵌）
- 悬停：提升阴影 `rgba(0, 0, 0, 0.18) 0px 0.5rem 1.5rem`

**玻璃白**
- 背景：`rgba(255, 255, 255, 0.18)`（磨砂玻璃）
- 文本：`#ffffff`
- 内边距：8px
- 圆角：12px（左对齐变体：`12px 0px 0px 12px`）
- 阴影：`rgba(0, 0, 0, 0.08) 0px 2px 8px`
- 悬停背景：`rgba(54, 22, 107, 0.14)`
- 用途：深色表面上的次要操作

**白色实色**
- 背景：`#ffffff`
- 文本：`#1f1633`
- 内边距：12px 16px
- 圆角：8px
- 悬停：背景过渡到 `#6a5fc1`，文本变为白色
- 焦点：背景 `#ffb287`（珊瑚色），轮廓 `rgb(106, 95, 193) solid 0.125rem`
- 用途：深色背景上的高可见度 CTA

**深紫罗兰（选择器/下拉框）**
- 背景：`#422082`
- 文本：`#ffffff`
- 内边距：8px 16px
- 圆角：8px

### 输入框

**文本输入**
- 背景：`#ffffff`
- 文本：`#1f1633`
- 边框：`1px solid #cfcfdb`
- 内边距：8px 12px
- 圆角：6px
- 焦点：边框颜色保持 `#cfcfdb`，阴影 `rgba(0, 0, 0, 0.15) 0px 2px 10px inset`

### 链接
- **深色背景默认**：`#ffffff`，下划线装饰
- **悬停**：颜色过渡到 `#6a5fc1`（Sentry 紫）
- **紫色链接**：`#6a5fc1` 默认，悬停下划线
- **青柠强调链接**：`#c2ef4e` 默认，悬停到 `#6a5fc1`
- **深色上下文链接**：`#362d59`，悬停到 `#ffffff`

### 卡片与容器
- 背景：半透明或深紫色表面
- 圆角：8px–12px
- 阴影：`rgba(0, 0, 0, 0.1) 0px 10px 15px -3px`
- 背景滤镜：`blur(18px) saturate(180%)` 用于玻璃效果

### 导航
- 深色透明标题栏覆盖主体内容
- Rubik 15px 字重 500 用于导航链接
- 白色文本，悬停到 Sentry 紫（`#6a5fc1`）
- 大写字母标签带 0.2px 字间距用于分类
- 移动端：汉堡菜单，全宽展开

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 比例：1px, 2px, 4px, 5px, 6px, 8px, 12px, 16px, 24px, 32px, 40px, 44px, 45px, 47px

### 网格与容器
- 最大内容宽度：1152px（XL 断点）
- 响应式内边距：2rem（移动端）→ 4rem（平板及以上）
- 内容在容器内居中
- 全宽深色区块包含内部内容

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动端 | < 576px | 单列，堆叠布局 |
| 小平板 | 576–640px | 微小宽度调整 |
| 平板 | 640–768px | 开始双列 |
| 小桌面 | 768–992px | 完整导航可见 |
| 桌面 | 992–1152px | 标准布局 |
| 大桌面 | 1152–1440px | 最大宽度内容 |

### 留白哲学
- **深色呼吸空间**：区块之间 generous 的垂直间距（64px–80px+）让深色背景作为视觉休息。
- **内容岛屿**：功能区块是漂浮在深紫色海洋中的自包含区块，每个都有自己的内部间距节奏。
- **不对称内边距**：按钮使用不对称内边距模式（12px 16px, 8px 12px）感觉有机而非僵硬。

### 圆角比例
- 最小（6px）：表单输入、小型交互元素
- 标准（8px）：按钮、卡片、容器
- 舒适（10px–12px）：大型容器、玻璃面板
- 圆润（13px）：主柔和按钮
- 药丸（18px）：图像容器、徽章

## 6. 深度与海拔

| 级别 | 处理 | 用途 |
|-------|-----------|-----|
| 下沉（级别 -1） | 内阴影 `rgba(0, 0, 0, 0.1) 0px 1px 3px inset` | 主按钮（触觉按压感） |
| 平面（级别 0） | 无阴影 | 默认表面、深色背景 |
| 表面（级别 1） | `rgba(0, 0, 0, 0.08) 0px 2px 8px` | 玻璃按钮、微妙卡片 |
| 提升（级别 2） | `rgba(0, 0, 0, 0.1) 0px 10px 15px -3px` | 卡片、浮动面板 |
| 突出（级别 3） | `rgba(0, 0, 0, 0.18) 0px 0.5rem 1.5rem` | 悬停状态、模态框 |
| 环境（级别 4） | `rgba(22, 15, 36, 0.9) 0px 4px 4px 9px` | 主体周围的深紫色环境光晕 |

**阴影哲学**：Sentry 使用独特的内阴影组合（按钮感觉按入表面）和环境光晕（内容从深色背景辐射出来）。深紫色环境阴影（`rgba(22, 15, 36, 0.9)`）是标志性特征——它创造出生物发光的质感，内容仿佛发出自己的紫色光芒。

## 7. 宜与忌

### 宜
- 使用深紫背景（`#1f1633`、`#150f23`）—— 永不使用纯黑（`#000000`）
- 在主按钮上应用内阴影以创造触觉按压效果
- 仅将 Dammit Sans 用于主体/展示标题 —— Rubik 用于其他所有地方
- 在按钮和标签上应用 `text-transform: uppercase` 配合 `letter-spacing: 0.2px`
- 节制使用青柠绿强调色（`#c2ef4e`）以获得最大影响力
- 对分层表面使用磨砂玻璃效果（`blur(18px) saturate(180%)`）
- 保持温暖的紫色阴影色调 —— 阴影应感觉带紫色调，而非中性灰
- 使用 Rubik 的四层字重系统：400（正文）、500（导航/强调）、600（标题）、700（CTA）

### 忌
- 不要使用纯黑（`#000000`）作为背景 —— 始终使用温暖的紫黑色
- 不要将 Dammit Sans 用于正文文本或 UI 元素 —— 它仅用于展示
- 不要使用标准灰色（`#666`、`#999`）作为边框 —— 使用紫色调灰色（`#362d59`、`#584674`）
- 不要放弃按钮的大写处理 —— 这是全系统模式
- 不要使用尖角（0px 圆角）—— 所有交互元素最小 6px
- 不要在同一组件中混合青柠绿强调色与珊瑚/粉色强调色
- 不要在主按钮上使用平面（非内嵌）阴影 —— 触觉质感是标志性特征
- 不要忘记大写字母文本的字间距 —— 最小 0.2px

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动端 | <576px | 单列、汉堡导航、堆叠 CTA |
| 平板 | 576–768px | 开始双列功能网格 |
| 小桌面 | 768–992px | 完整导航、并排布局 |
| 桌面 | 992–1152px | 最大宽度容器、完整布局 |
| 大 | >1152px | 保持内容最大宽度、 generous 边距 |

### 折叠策略
- 主体文本：88px Dammit Sans → 60px → 移动端比例
- 导航：水平 → 带滑出的汉堡包
- 功能区块：并排 → 堆叠卡片
- 按钮：行内 → 移动端全宽堆叠
- 容器内边距：4rem → 2rem

### 迭代指南
1. 始终从深紫背景开始 —— 调色板是为深色模式构建的
