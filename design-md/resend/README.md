# Resend 风格设计系统

[DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/resend/DESIGN.md) 提取自公开的 [resend](https://resend.com/) 网站。这不是官方设计系统。颜色、字体和间距可能并非 100% 精确，但它是构建类似风格的良好起点。

## 文件

| 文件 | 说明 |
|------|------|
| `DESIGN.md` | 完整设计系统文档（9 个章节） |
| `preview.html` | 交互式设计令牌目录（亮色） |
| `preview-dark.html` | 交互式设计令牌目录（暗色） |

使用 [DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/resend/DESIGN.md) 作为 AI 智能体（Claude、Cursor、Stitch）生成 Resend 风格 UI 的参考。
