# 设计系统：Claude (Anthropic)

## 1. 视觉主题与氛围

Claude 的界面如同一个被重新构想为产品页面的文学沙龙——温暖、从容且静谧而富有知性。整个体验建立在羊皮纸色调的画布 (`#f5f4ed`) 之上，刻意唤起高品质纸张而非数字表面的质感。当大多数 AI 产品页面倾向于冷峻的未来主义美学时，Claude 的设计却散发着人性的温暖，仿佛这位 AI 本身对室内设计颇有品味。

最具标志性的设计是自定义的 Anthropic Serif 字体——这是一种中等字重、比例舒展的衬线体，赋予每个标题如同书名般的庄重感。结合陶土色 (`#c96442`)、黑色和柔和绿色的有机手绘风格插图，视觉语言传达出"贴心的伙伴"而非"强大的工具"。衬线标题在紧凑而舒适的行高 (1.10–1.30) 下呼吸，营造出一种读散文而非浏览产品页面的节奏感。

Claude 设计的真正独特之处在于其温暖的中性色调。每个灰色都带有黄棕色调 (`#5e5d59`、`#87867f`、`#4d4c48`)——没有任何冷调的蓝灰色。边框呈奶油色调 (`#f0eee6`、`#e8e6dc`)，阴影使用温暖的透明黑色，甚至最深的表面 (`#141413`、`#30302e`) 也带有几乎难以察觉的橄榄暖意。这种色彩一致性营造出一个既温馨又可信的空间。

**核心特征：**
- 温暖的羊皮纸画布 (`#f5f4ed`)，唤起高品质纸张而非屏幕的质感
- 自定义 Anthropic 字体家族：标题使用 Serif，UI 使用 Sans，代码使用 Mono
- 陶土色品牌点缀 (`#c96442`)——温暖、质朴、刻意的非科技感
- 纯粹暖色调中性色——每个灰色都带有黄棕底色
- 有机编辑风格的插图，取代典型的科技图标
- 环形阴影系统 (`0px 0px 0px 1px`)，在不使用可见边框的情况下营造类边框的深度感
- 杂志般的版面节奏，宽敞的区块间距和衬线驱动的层级

## 2. 色板与角色

### 主色
- **Anthropic 近黑** (`#141413`)：主要文本色和深色主题表面——不是纯黑，而是一种温暖的、近乎橄榄色调的深色，对眼睛更柔和。这是所有主要科技品牌中最温暖的"黑色"。
- **陶土品牌色** (`#c96442`)：核心品牌色——一种焦橙棕色，用于主要 CTA 按钮、品牌时刻和标志性点缀。刻意质朴且非科技感。
- **珊瑚点缀色** (`#d97757`)：品牌色的较浅、较暖变体，用于文本点缀、深色表面上的链接和次要强调。

### 次要色与点缀色
- **错误深红** (`#b53333`)：一种深沉的暖红色，用于错误状态——严肃但不引起恐慌。
- **聚焦蓝** (`#3898ec`)：用于输入框聚焦环的标准蓝色——整个系统中唯一的冷色，纯粹为无障碍性而设。

### 表面与背景
- **羊皮纸** (`#f5f4ed`)：主要页面背景——一种带有黄绿色调的温暖奶油色，感觉如同陈年纸张。是整个设计的情感基石。
- **象牙白** (`#faf9f5`)：最浅的表面——用于羊皮纸背景上的卡片和悬浮容器。几乎难以区分，但营造出微妙的层次感。
- **纯白** (`#ffffff`)：专用于特定按钮表面和最大对比度元素。
- **暖沙** (`#e8e6dc`)：按钮背景和突出的交互表面——一种明显偏暖的浅灰色。
- **深色表面** (`#30302e`)：深色主题容器、导航边框和悬浮深色元素——温暖的炭灰色。
- **深暗** (`#141413`)：深色主题页面背景和主要深色表面。

### 中性色与文本
- **暖炭** (`#4d4c48`)：浅色暖表面上的按钮文本——明浅文本的首选深色。
- **橄榄灰** (`#5e5d59`)：次要正文——一种明显的暖中深灰色。
- **石灰** (`#87867f`)：三级文本、脚注和弱化的元数据。
- **深暖** (`#3d3d3a`)：深色文本链接和强调的次要文本。
- **暖银** (`#b0aea5`)：深色表面上的文本——一种带有羊皮纸色调的暖浅灰色。

### 语义与点缀
- **边框奶油** (`#f0eee6`)：标准浅色主题边框——几乎不可见的暖奶油色，营造最柔和的包容感。
- **边框暖** (`#e8e6dc`)：醒目的边框、分隔线和浅色表面上的强调包容。
- **边框深** (`#30302e`)：深色表面上的标准边框——保持温暖的色调。
- **环暖** (`#d1cfc5`)：用于按钮悬浮/聚焦状态的阴影环颜色。
- **环微妙** (`#dedc01`)：用于较浅交互表面的次要环变体。
- **环深** (`#c2c0b6`)：用于激活/按下状态的更深环。

### 渐变系统
- Claude 的设计在传统意义上**不使用渐变**。深度和视觉丰富度来自暖色调表面、有机插图和明暗区块交替的相互作用。温暖的调色板本身随着视线在奶油色→沙色→石灰色→炭灰色→黑色区块间移动而营造出"渐变"效果。

## 3. 排版规则

### 字体家族
- **标题**：`Anthropic Serif`，备用：`Georgia`
- **正文/UI**：`Anthropic Sans`，备用：`Arial`
- **代码**：`Anthropic Mono`，备用：`Arial`

*注：这些是自定义字体。对于外部实现，Georgia 作为衬线体替代，system-ui/Inter 作为无衬线体替代。*

### 原则
- **衬线传达权威，无衬线服务功能**：Anthropic Serif 承载所有标题内容，使用中等字重 (500)，赋予每个标题如同出版标题般的庄重感。Anthropic Sans 高效处理所有功能性 UI 文本——按钮、标签、导航。
- **衬线单字重**：所有 Anthropic Serif 标题使用字重 500——无粗体，无细体。这在所有标题尺寸间创造出一致的"声线"，仿佛同一位作者撰写了每个标题。
- **宽松的行高**：大多数正文使用 1.60 的行高——明显比典型科技网站 (1.4–1.5) 更宽松。这营造出接近书籍而非仪表盘的阅读体验。
- **紧凑但不拥挤的标题**：1.10–1.30 的标题行高紧凑但从不局促。衬线字体需要无衬线字体不需要的呼吸空间。
- **标签微字距**：小型无衬线文本 (12px 及以下) 使用刻意设计的字间距 (0.12px–0.5px) 以保持微小尺寸下的可读性。

## 4. 组件样式

### 按钮

**暖沙（次要）**
- 背景：暖沙 (`#e8e6dc`)
- 文本：暖炭 (`#4d4c48`)
- 内边距：0px 12px 0px 8px（不对称——图标优先布局）
- 圆角：舒适的圆角 (8px)
- 阴影：基于环 (`#e8e6dc 0px 0px 0px 0px, #d1cfc5 0px 0px 0px 1px`)
- 主力按钮——温暖、低调、明显的交互性

**白色表面**
- 背景：纯白 (`#ffffff`)
- 文本：Anthropic 近黑 (`#141413`)
- 内边距：8px 16px 8px 12px
- 圆角：慷慨的圆角 (12px)
- 悬浮：切换到次要背景色
- 干净、悬浮感的浅色表面按钮

**深炭**
- 背景：深色表面 (`#30302e`)
- 文本：象牙白 (`#faf9f5`)
- 内边距：0px 12px 0px 8px
- 圆角：舒适的圆角 (8px)
- 阴影：基于环 (`#30302e 0px 0px 0px 0px, ring 0px 0px 0px 1px`)
- 用于明暗对比强调的反转变体

**品牌陶土**
- 背景：陶土品牌色 (`#c96442`)
- 文本：象牙白 (`#faf9f5`)
- 圆角：8–12px
- 阴影：基于环 (`#c96442 0px 0px 0px 0px, #c96442 0px 0px 0px 1px`)
- 主要 CTA——唯一使用彩色色的按钮

**深色主题**
- 背景：Anthropic 近黑 (`#141413`)
- 文本：暖银 (`#b0aea5`)
- 内边距：9.6px 16.8px
- 圆角：慷慨的圆角 (12px)
- 边框：细实线深色表面 (`1px solid #30302e`)
- 用于深色主题表面

### 卡片与容器
- 背景：浅色表面上使用象牙白 (`#faf9f5`) 或纯白 (`#ffffff`)；深色表面上使用深色表面 (`#30302e`)
- 边框：浅色表面上细实线边框奶油 (`1px solid #f0eee6`)；深色表面上 `1px solid #30302e`
- 圆角：标准卡片使用舒适的圆角 (8px)；精选卡片使用慷慨的圆角 (16px)；英雄容器和嵌入式媒体使用非常圆角 (32px)
- 阴影：轻柔阴影 (`rgba(0,0,0,0.05) 0px 4px 24px`) 用于悬浮内容
- 环形阴影：`0px 0px 0px 1px` 模式用于交互卡片状态
- 区块边框：`1px 0px 0px`（仅顶部）用于列表项分隔

### 输入框与表单
- 文本：Anthropic 近黑 (`#141413`)
- 内边距：1.6px 12px（垂直方向非常紧凑）
- 边框：标准暖色边框
- 聚焦：带聚焦蓝 (`#3898ec`) 边框颜色的环——唯一的冷色时刻
- 圆角：慷慨的圆角 (12px)

### 导航
- 粘性顶部导航，温暖背景
- Logo：Claude 文字标识，使用 Anthropic 近黑
- 链接：混合使用近黑 (`#141413`)、橄榄灰 (`#5e5d59`) 和深暖 (`#3d3d3a`)
- 导航边框：`1px solid #30302e` (深色) 或 `1px solid #f0eee6` (浅色)
- CTA：陶土品牌色按钮或白色表面按钮
- 悬浮：文本切换到前景主色，无装饰

### 图片处理
- 展示 Claude 聊天界面的产品截图
- 媒体使用慷慨的边框圆角 (16–32px)
- 嵌入式视频播放器带圆角
- 深色 UI 截图在温暖浅色画布上形成对比
- 概念区块使用有机手绘插图

### 特色组件

**模型对比卡片**
- Opus 4.5、Sonnet 4.5、Haiku 4.5 以干净的卡片网格展示
- 每个模型获得带边框的卡片，包含名称、描述和能力徽章
- 边框暖 (`#e8e6dc`) 分隔项目

**有机插图**
- 陶土色、黑色和柔和绿色的手绘风格矢量插图
- 抽象、概念性而非字面的产品图解
- 主要的视觉个性——没有其他 AI 公司使用这种风格

**明暗区块交替**
- 页面在羊皮纸浅色和近黑深色区块之间交替
- 创造出如书籍章节般的阅读节奏
- 每个区块都感觉像一个独特的环境

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 刻度：3px、4px、6px、8px、10px、12px、16px、20px、24px、30px
- 按钮内边距：不对称 (0px 12px 0px 8px) 或平衡 (8px 16px)
- 卡片内边距：约 24–32px
- 区块垂直间距：宽敞 (主要区块之间估计 80–120px)

### 网格与容器
- 最大容器宽度：约 1200px，居中
- 英雄区：居中，编辑风格布局
- 功能区块：单列或 2–3 列卡片网格
- 模型对比：干净的 3 列网格
- 全宽深色区块打破容器以强调

### 留白理念
- **编辑节奏**：每个区块像杂志跨页般呼吸——宽敞的上下边距创造自然的阅读停顿。
- **衬线驱动的节奏**：衬线标题建立文学节奏，比无衬线设计需要更多留白。
- **内容岛方法**：区块在明暗环境之间交替，为每条信息创造独特的"房间"。

### 圆角刻度
- 锐利 (4px)：最小行内元素
- 微圆 (6–7.5px)：小按钮、次要交互元素
- 舒适圆角 (8–8.5px)：标准按钮、卡片、容器
- 慷慨圆角 (12px)：主要按钮、输入框、导航元素
- 非常圆角 (16px)：精选容器、视频播放器、标签列表
- 高度圆角 (24px)：标签式元素、高亮容器
- 最大圆角 (32px)：英雄容器、嵌入式媒体、大卡片

## 6. 深度与高程

| 级别 | 处理方式 | 用途 |
|-------|-----------|-----|
| 平面 (Level 0) | 无阴影，无边框 | 羊皮纸背景、行内文本 |
| 包容 (Level 1) | `1px solid #f0eee6` (浅色) 或 `1px solid #30302e` (深色) | 标准卡片、区块 |
| 环 (Level 2) | 使用暖灰色的 `0px 0px 0px 1px` 环阴影 | 交互卡片、按钮、悬浮状态 |
| 低语 (Level 3) | `rgba(0,0,0,0.05) 0px 4px 24px` | 精选功能卡片、产品截图 |
| 内嵌 (Level 4) | 15% 透明度的 `inset 0px 0px 0px 1px` | 激活/按下按钮状态 |

**阴影理念**：Claude 通过**暖色调环阴影**而非传统投影来传达深度。标志性的 `0px 0px 0px 1px` 模式创造出比实际边框更柔和的类边框光晕——它是伪装成边框的阴影，或是技术上为阴影的边框。当投影确实出现时，它们极其柔和 (0.05 透明度，24px 模糊)——几乎不可见的悬浮感，暗示漂浮而非投射。

### 装饰深度
- **明/暗交替**：最戏剧性的深度效果来自羊皮纸 (`#f5f4ed`) 和近黑 (`#141413`) 区块之间的交替——整个区块通过改变环境光级别来改变高程。
- **暖环光晕**：按钮和卡片交互使用与温暖调色板匹配的环阴影——从不使用冷色调或通用灰色。

## 7. 注意事项

### 应当
- 使用羊皮纸 (`#f5f4ed`) 作为主要浅色背景——温暖的奶油色调就是 Claude 的个性
- 对所有标题使用字重 500 的 Anthropic Serif——单字重一致性是有意为之
- 仅将陶土品牌色 (`#c96442`) 用于主要 CTA 和最高信号的品牌时刻
- 保持所有中性色为暖色调——每个灰色都应有黄棕底色
- 使用环阴影 (`0px 0px 0px 1px`) 处理交互元素状态而非投影
- 维持编辑风格的衬线/无衬线层级——衬线用于内容标题，无衬线用于 UI
- 使用宽松的正文字高 (1.60) 营造文学阅读体验
- 在明暗区块之间交替以创造章节般的页面节奏
- 对按钮和卡片应用慷慨的边框圆角 (12–32px) 以营造柔和亲切的感觉

### 不应当
- 不要在任何地方使用冷调蓝灰色——调色板纯粹是暖色调的
- 不要对 Anthropic Serif 使用粗体 (700+)——字重 500 是衬线的上限
- 不要引入超出陶土色的饱和色——调色板刻意柔和
- 不要在按钮或卡片上使用锐利边角 (< 6px 半径)——柔和是身份的核心
- 不要使用重投影——深度来自环阴影和背景色 shifts
- 不要使用纯白 (`#ffffff`) 作为页面背景——羊皮纸 (`#f5f4ed`) 或象牙白 (`#faf9f5`) 总是更温暖
- 不要使用几何/科技风格插图——Claude 的插图是有机的、手绘风格的
- 不要将正文行高降低到 1.40 以下——宽松的间距支持编辑个性
- 不要对非代码内容使用等宽字体——Anthropic Mono 严格用于代码
- 不要在标题中混入无衬线字体——衬线/无衬线分割是排版身份

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 小移动设备 | <479px | 最小布局，所有内容堆叠，紧凑排版 |
| 移动设备 | 479–640px | 单列，汉堡导航，缩减标题尺寸 |
| 大移动设备 | 640–767px | 稍宽的内容区 |
| 平板 | 768–991px | 开始 2 列网格，浓缩导航 |
| 桌面 | 992px+ | 完整多列布局，展开导航，最大英雄排版 (64px) |

### 触摸目标
- 按钮使用慷慨的内边距 (垂直最小 8–16px)
- 导航链接间距充足，便于拇指导航
- 卡片表面作为大触摸目标
- 最小推荐：44x44px

### 折叠策略
- **导航**：完整水平导航在移动端折叠为汉堡菜单
- **功能区块**：多列 → 堆叠单列
- **英雄文本**：64px → 36px → ~25px 渐进缩放
- **模型卡片**：3 列 → 垂直堆叠
- **区块内边距**：成比例缩减但维持编辑节奏
- **插图**：成比例缩放，保持宽高比

### 图片行为
- 产品截图在圆角容器内成比例缩放
- 插图在所有尺寸下保持质量
- 视频嵌入保持 16:9 宽高比并带圆角
- 断点间无艺术指导变化
