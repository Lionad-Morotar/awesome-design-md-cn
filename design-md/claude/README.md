# Claude 风格设计系统

[DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/claude/DESIGN.md) 提取自公开的 [claude](https://claude.ai/) 网站。这不是官方设计系统。颜色、字体和间距可能并非 100% 准确。但它是构建类似风格作品的良好起点。

## 文件

| 文件 | 说明 |
|------|------|
| `DESIGN.md` | 完整的设计系统文档（9 个章节） |
| `preview.html` | 交互式设计令牌目录（浅色模式） |
| `preview-dark.html` | 交互式设计令牌目录（深色模式） |


使用 [DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/claude/DESIGN.md) 作为 AI 智能体（Claude、Cursor、Stitch）的参考，以生成符合 Claude 设计语言的 UI。

## 预览

使用 DESIGN.md 构建的示例落地页。它在一个页面中展示了实际的颜色、排版、按钮、卡片、间距和阴影效果。
