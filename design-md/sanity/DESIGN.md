# 设计系统：Sanity

## 1. 视觉主题与氛围

Sanity 的网站是一个开发者内容平台，渲染为夜间指挥中心——黑暗、精确且深度结构化。整个体验置于近黑色画布（`#0b0b0b`）之上，读起来不像"深色模式切换"，更像是为生活在终端中的人构建的工具的自然状态。大多数 CMS 营销页面追求友好的粉彩色柔和插图，而 Sanity 则倾向于其产品的重力：结构化内容值得一个结构化的舞台。

标志性字体声音是 waldenburgNormal——一种独特的、略带几何感的无衬线字体，具有紧密的负字间距（显示尺寸下为 -0.32px 至 -4.48px），赋予标题压缩的、工程化的质感。在 112px 英雄标题尺寸下，字距为 -4.48px，字体感觉几乎是机械加工的——如同精密切割的钢制字形。这与用于代码和技术标签的 IBM Plex Mono 配对，创造出双重注册声音：编辑权威性 meets 开发者可信度。

让 Sanity 独具特色的是其单色深色调色板与生动、饱和的强调标点之间的相互作用。中性色阶从纯黑通过严格控制的灰色渐变（`#0b0b0b` -> `#212121` -> `#353535` -> `#797979` -> `#b9b9b9` -> `#ededed` -> `#ffffff`），无暖色或冷色偏见——只有纯粹的、消色差的精确性。在这个纪律严明的背景前，霓虹绿强调色（display-p3 green）和电蓝色（`#0052ef`）以深色控制室中信号灯的冲击力呈现。橙红色 CTA（`#f36458`）提供了这个原本冷色系统中唯一的暖色调。

**关键特征：**
- 近黑色画布（`#0b0b0b`）作为默认自然环境——不是深色"模式"而是主要身份
- waldenburgNormal 在显示尺寸下具有极端负字距，创造出精密工程化的字体声音
- 纯粹的消色差灰色阶——无暖色或冷色底色，纯粹的中性纪律
- 生动的强调标点：霓虹绿、电蓝（`#0052ef`）和珊瑚红（`#f36458`）衬托在深色背景上
- 圆角主按钮（99999px 半径）与次要动作的微妙圆角矩形（3-6px）形成对比
- IBM Plex Mono 作为编辑显示字体的技术对应物
- 全出血深色区域，内容包含在测量后的最大宽度容器中
- 所有交互元素的悬停状态切换为电蓝色（`#0052ef`）——一致的"激活"信号

## 2. 色板与角色

### 主品牌
- **Sanity 黑** (`#0b0b0b`): 主画布和主导表面颜色。不是纯黑但足够接近绝对感。整个视觉身份的基础。
- **纯黑** (`#000000`): 用于最大对比度时刻、深度叠加和某些边框强调。
- **Sanity 红** (`#f36458`): 主 CTA 和品牌强调——暖珊瑚红，作为主要行动号召颜色。用于"开始使用"按钮和主要转化点。

### 强调与交互
- **电蓝** (`#0052ef`): 整个系统的通用悬停/激活状态颜色。按钮、链接和交互元素在悬停时都切换到此蓝色。也用作 `--color-blue-700` 用于焦点环和激活状态。
- **浅蓝** (`#55beff` / `#afe3ff`): 次要蓝色变体，用于强调背景、徽章和变暗的蓝色表面。
- **霓虹绿** (`color(display-p3 .270588 1 0)`): 生动、广域绿色，用作 `--color-fg-accent-green` 用于成功状态和高级功能亮点。在 sRGB 中回退到 `#19d600`。
- **强调洋红** (`color(display-p3 .960784 0 1)`): 生动的广域洋红色，用于特殊强调时刻。

### 表面与背景
- **近黑** (`#0b0b0b`): 默认页面背景和主要表面。
- **深灰** (`#212121`): 卡片、次要容器、输入背景和微妙分层高于基础画布的 elevating 表面颜色。
- **中深灰** (`#353535`): 用于在深色层之间创建深度的第三表面和边框颜色。
- **纯白** (`#ffffff`): 用于反转区域、深色背景上的文本和特定按钮表面。
- **浅灰** (`#ededed`): 反转/浅色区域的浅色表面和微妙背景色调。

### 中性色与文本
- **白色** (`#ffffff`): 深色表面上的主要文本颜色，最大可读性。
- **银色** (`#b9b9b9`): 次要文本、深色表面上的正文、柔和的描述和占位符文本。
- **中灰** (`#797979`): 第三文本、元数据、时间戳和弱化的内容。
- **炭灰** (`#212121`): 浅色/反转表面上的文本。
- **近黑文本** (`#0b0b0b`): 白色/浅色按钮表面上的主要文本。

### 语义色
- **错误红** (`#dd0000`): 破坏性操作、验证错误和关键警告——高饱和度的纯红色。
- **GPC 绿** (`#37cd84`): 隐私/合规指示器绿色。
- **焦点环蓝** (`#0052ef`): 可访问性的焦点环颜色，与交互蓝色匹配。

### 边框系统
- **深边框** (`#0b0b0b`): 深色容器上的主要边框——几乎不可见，保持最小包含。
- **微妙边框** (`#212121`): 深色表面上输入框、文本区域和卡片边缘的标准边框。
- **中等边框** (`#353535`): 用于强调包含和分隔线的更可见边框。
- **浅边框** (`#ffffff`): 反转/浅色元素或需要对比分离的按钮上的边框。
- **橙色边框** (`color(display-p3 1 0.3333 0)`): 用于高亮/特色元素的特殊强调边框。

## 3. 排版规则

### 字体族
- **显示/标题**: `waldenburgNormal`, fallback: `waldenburgNormal Fallback, ui-sans-serif, system-ui`
- **正文/UI**: `waldenburgNormal`, fallback: `waldenburgNormal Fallback, ui-sans-serif, system-ui`
- **代码/技术**: `IBM Plex Mono`, fallback: `ibmPlexMono Fallback, ui-monospace`
- **回退/CJK**: `Helvetica`, fallback: `Arial, Hiragino Sans GB, STXihei, Microsoft YaHei, WenQuanYi Micro Hei`

*注意：waldenburgNormal 是自定义字体。对于外部实现，使用 Inter 或 Space Grotesk 作为无衬线替代（几何、略微压缩的感觉）。IBM Plex Mono 可在 Google Fonts 上获取。*

### 原则
- **大尺寸下的极端负字距**: 72px+ 的显示标题使用激进负字距（-2.88px 至 -4.48px），创造出区别于宽松编辑字体的紧密、工程化质感。
- **单一字体，多重注册**: waldenburgNormal 处理编辑显示和功能 UI 文本。字重范围狭窄（大多数为 400-425，500-600 仅用于微小标签），保持声音一致。
- **OpenType 特性控制**: 字体使用有意的特性设置，包括显示尺寸的 `"cv01", "cv11", "cv12", "cv13", "ss07"` 和正文的 `"calt" 0`，为不同上下文微调字符替代。
- **紧密标题，宽松正文**: 标题使用 1.00-1.24 行高（极紧密），而正文在 1.50 呼吸。此对比创建清晰的视觉层级。
- **技术标签使用大写**: IBM Plex Mono 说明和小标签经常使用 `text-transform: uppercase` 配合紧密行高，为技术元数据创造"系统读取"美学。

## 6. 深度与层次

### 阴影系统

| 级别 | 值 | 用法 |
|-------|-------|-------|
| Level 0 (平面) | none | 大多数元素的默认状态——深色表面仅通过颜色创造深度 |
| Level 1 (微妙) | 0px 0px 0px 1px `#212121` | 最小包含的边框式阴影，无可见边框 |
| Level 2 (焦点) | 0 0 0 2px `var(--color-blue-500)` | 输入框和交互元素的焦点环 |
| Level 3 (叠加) | 背景模糊 + 半透明深色 | 导航叠加、模态框背景 |

### 深度哲学
Sanity 的深度系统几乎完全是**色彩学**而非基于阴影。层次通过表面颜色切换传达：`#0b0b0b` (地面) -> `#212121` (elevated) -> `#353535` (突出) -> `#ffffff` (反转/最高)。这种方法原生适用于深色界面，传统投影在其中会不可见。存在的少数阴影是基于环状（0px 0px 0px Npx）或基于模糊（backdrop-filter）而非偏移阴影，保持扁平、精密工程美学。

基于边框的包含（1px 实线 `#212121` 或 `#353535`）作为主要空间分隔符，边框黑暗度校准为可见但不主导。系统避免"浮动卡片"美学——所有内容感觉安装到表面上而非悬浮其上。

## 7. 宜与忌

### 宜
- 使用消色差灰色阶作为基础——保持纯粹的中性纪律，无暖/冷色调
- 在所有交互元素上一致应用电蓝 (`#0052ef`) 作为通用悬停/激活状态
- 在 48px 及以上的显示标题上应用极端负字距（-2px 至 -4.48px）
- 保持主 CTA 为全圆角形状（99999px 半径）配合珊瑚红 (`#f36458`)
- 使用 IBM Plex Mono 大写用于技术标签、标签和系统元数据
- 通过表面颜色（深到浅）而非阴影传达深度
- 在深色画布上保持慷慨的垂直章节间距（64-120px）
- 使用 `"cv01", "cv11", "cv12", "cv13", "ss07"` OpenType 特性用于显示排版

### 忌
- 不要引入暖色或冷色色调到中性色阶——Sanity 的灰色是纯粹消色差
- 不要使用投影实现层次——深色界面需要色彩深度
- 不要使用 13px 到 99998px 之间的圆角——系统从 12px (大卡片) 直接跳到圆角 (99999px)
- 不要在同一个元素中混合珊瑚红 CTA 与电蓝交互色
- 不要使用重字体字重 (700+)——系统最大到 600，仅用于 11px 大写标签
- 不要在浅色表面上放置浅色文本或在深色表面上放置深色文本而不检查灰度对比度
- 不要使用传统偏移 box-shadows——仅使用环状阴影 (0 0 0 Npx) 或基于边框的包含
- 不要破坏标题的紧密行高——1.00-1.24 是范围，显示文本永远不要到 1.5+

- **导航**: 低于 768px 时水平链接折叠为汉堡菜单
- **英雄排版**: 跨断点从 112px -> 72px -> 48px -> 38px 缩放，保持紧密字距比例
- **网格布局**: 3 列 -> 2 列在 ~960px，低于 768px 为单列
- **卡片网格**: 移动端水平滚动而非环绕（保持卡片宽高比）
- **章节间距**: 移动端垂直内边距减少约 40%（120px -> 64px -> 48px）
- **按钮尺寸**: CTA 圆角保持内边距但减少字体尺寸；幽灵按钮保持固定
- **代码块**: 水平滚动配合保留的等宽格式

### 移动端特定调整
- 全出血区域边缘到边缘延伸，内部边距 16px
- 触摸目标：所有交互元素最小 44px
- 标题字间距在移动端尺寸略微放松（较不激进的负字距）
- 图像容器从固定宽高比切换到全宽配合自动高度
