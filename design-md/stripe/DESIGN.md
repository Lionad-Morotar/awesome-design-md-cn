# 设计系统：Stripe

## 1. 视觉主题与氛围

Stripe 的网站是金融科技设计的黄金标准——这个系统既能同时传达技术感和精致感，又能兼顾精准与温暖。页面以纯净的白色画布 (`#ffffff`) 开场，搭配深海军蓝标题 (`#061b31`) 和标志性紫色 (`#533afd`)，后者既作为品牌锚点又作为交互强调色。这并非企业软件那种冰冷的紫色；而是一种浓郁饱和的紫罗兰色，传递出自信与高级感。整体印象宛如一家由世界级字体设计工坊重新打造的金融机构。

自定义的 `sohne-var` 可变字体是 Stripe 视觉识别系统的决定性元素。所有文本元素都启用 OpenType `"ss01"` 风格集，该风格集修改字符形状，呈现出独特的几何感和现代感。在大标题尺寸下（48px-56px），sohne-var 使用 300 字重——这对于标题来说是极轻的字重，营造出空灵般、近乎低语的权威感。这与"粗体英雄标题"的惯例截然相反；Stripe 的标题仿佛无需大声宣告。在较小尺寸下，系统同样使用 300 字重，并按比例减少字距调整，同时通过 `"tnum"` 启用表格数字用于金融数据显示。

真正让 Stripe 独树一帜的是其阴影系统。Stripe 并非采用大多数网站的平面或单层阴影，而是使用多层蓝色调阴影：标志性的 `rgba(50,50,93,0.25)` 结合 `rgba(0,0,0,0.1)` 创造出带有冷色调、近乎大气深度的阴影——仿佛元素漂浮在暮色天空中。主阴影颜色 (50,50,93) 的蓝灰色底色直接与海军蓝 - 紫色品牌调色板相呼应，使得即使 Elevation 也符合品牌调性。

**关键特征：**
- 所有文本均使用带 OpenType `"ss01"` 的 sohne-var——这是定义品牌字形的自定义风格集
- 300 字重作为标志性标题字重——轻盈、自信、反常规
- 大标题尺寸下的负字距（56px 时为 -1.4px，向下逐级松弛）
- 使用 `rgba(50,50,93,0.25)` 的蓝色调多层阴影——Elevation 呈现品牌色彩
- 深海军蓝 (`#061b31`) 标题而非黑色——温暖、高级、金融级
- 保守的圆角半径（4px-8px）——无药丸形状，无锐利边缘
- 红宝石色 (`#ea2261`) 和洋红色 (`#f96bee`) 作为渐变和装饰元素的强调色
- `SourceCodePro` 作为等宽字体伴侣，用于代码和技术标签

## 2. 色彩调色板与角色

### 主色
- **Stripe 紫** (`#533afd`)：主品牌色、CTA 背景、链接文本、交互高亮。一种饱和的蓝紫色，锚定整个系统。
- **深海军蓝** (`#061b31`)：`--hds-color-heading-solid`。主标题色。不是黑色，不是灰色——一种非常深的蓝色，为文本增添温暖与深度。
- **纯白** (`#ffffff`)：页面背景、卡片表面、深色背景上的按钮文本。

### 品牌色与深色
- **品牌深** (`#1c1e54`)：`--hds-color-util-brand-900`。深靛蓝色，用于深色区域、页脚背景和沉浸式品牌时刻。
- **暗海军蓝** (`#0d253d`)：`--hds-color-core-neutral-975`。最深的中性色——近乎黑色的底色带蓝色调，提供最大深度而不显生硬。

### 强调色
- **红宝石色** (`#ea2261`)：`--hds-color-accentColorMode-ruby-icon-solid`。暖调红粉色，用于图标、警报和强调元素。
- **洋红色** (`#f96bee`)：`--hds-color-accentColorMode-magenta-icon-gradientMiddle`。鲜艳的粉紫色，用于渐变和装饰高亮。
- **洋红浅** (`#ffd7ef`)：`--hds-color-util-accent-magenta-100`。用于洋红色主题卡片和徽章的染色表面。

### 交互色
- **主紫色** (`#533afd`)：主链接色、激活状态、选中元素。
- **紫色悬停** (`#4434d4`)：主元素悬停状态的深紫色。
- **深紫色** (`#2e2b8c`)：`--hds-color-button-ui-iconHover`。图标悬停状态的深紫色。
- **浅紫色** (`#b9b9f9`)：`--hds-color-action-bg-subduedHover`。柔和薰衣草色，用于低调悬停背景。
- **中紫色** (`#665efd`)：`--hds-color-input-selector-text-range`。范围选择器和输入高亮色。

### 中性色阶
- **标题** (`#061b31`)：主标题、导航文本、强标签。
- **标签** (`#273951`)：`--hds-color-input-text-label`。表单标签、次要标题。
- **正文** (`#64748d`)：次要文本、描述、说明文字。
- **成功绿** (`#15be53`)：状态徽章、成功指示器（背景/边框使用 0.2-0.4 透明度）。
- **成功文本** (`#108c3d`)：成功徽章文本颜色。
- **柠檬色** (`#9b6829`)：`--hds-color-core-lemon-500`。警告和高亮强调色。

### 表面与边框
- **默认边框** (`#e5edf5`)：卡片、分割线和容器的标准边框颜色。
- **紫色边框** (`#b9b9f9`)：按钮和输入框的激活/选中状态边框。
- **柔和紫边框** (`#d6d9fc`)：次要元素的微妙紫色调边框。
- **洋红边框** (`#ffd7ef`)：洋红色主题元素的粉色边框。
- **虚线边框** (`#362baa`)：用于拖放区域和占位符元素的虚线边框。

### 阴影色
- **阴影蓝** (`rgba(50,50,93,0.25)`)：标志性蓝色调主阴影色。
- **阴影深蓝** (`rgba(3,3,39,0.25)`)：用于提升元素的深蓝色阴影。
- **阴影黑** (`rgba(0,0,0,0.1)`)：深度强化的第二层阴影。
- **阴影环境光** (`rgba(23,23,23,0.08)`)：微妙提升的柔和环境阴影。
- **阴影柔和** (`rgba(23,23,23,0.06)`)：轻微抬升的最小环境阴影。

- **主字体**：`sohne-var`，回退：`SF Pro Display`

### 原则
- **轻字重作为标志性特征**：大标题尺寸下使用 300 字重是 Stripe 最具辨识度的排版选择。当其他设计使用 600-700 字重来吸引注意力时，Stripe 将轻盈视为奢华——文本足够自信，无需字重即可展现权威。
- **ss01 无处不在**：`"ss01"` 风格集是不可妥协的。它修改特定字形（可能是 alternate `a`、`g`、`l` 形式），在所有 sohne-var 文本上营造更具几何感、现代感的氛围。
- **两种 OpenType 模式**：`"ss01"` 用于展示/正文文本，`"tnum"` 用于金融数据中的表格数字。两者从不重叠——段落中的数字使用 ss01，数据表中的数字使用 tnum。
- **渐进式字距调整**：字距与尺寸成比例收紧：56px 时 -1.4px，48px 时 -0.96px，32px 时 -0.64px，26px 时 -0.26px，16px 及以下为正常。
- **双字重简洁性**：主要为 300（正文和标题）和 400（UI/按钮）。主字体中无粗体（700）——SourceCodePro 使用 500/700 实现代码对比。

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 缩放：1px, 2px, 4px, 6px, 8px, 10px, 11px, 12px, 14px, 16px, 18px, 20px
- 注意：该缩放尺度在小端密集（4-12 每 2px 递增），反映了 Stripe 面向金融数据的精确 UI

### 网格与容器
- 最大内容宽度：约 1080px
- 英雄区：居中单列带宽敞内边距，轻量级标题
- 功能区块：2-3 列网格用于功能卡片
- 全宽深色区块带 `#1c1e54` 背景用于品牌沉浸
- 代码/仪表板预览为带蓝色调阴影的容器卡片

### 留白哲学
- **精确间距**：与极简系统的大片空白不同，Stripe 使用经过测量、有目的的留白。每个间隙都是深思熟虑的排版选择。
- **密集数据，宽松外框**：金融数据展示（表格、图表）紧密打包，但周围的 UI 外框则宽松分布。这创造出一种受控的密度感——如同精美画框中组织有序的电子表格。
- **区块节奏**：白色区块与深色品牌区块 (`#1c1e54`) 交替出现，形成戏剧性的明/暗节奏，在不引入任意色彩的情况下防止单调。

### 圆角半径缩放
- 微型（1px）：细粒度元素，微妙圆角
- 标准（4px）：按钮、输入框、徽章、卡片——主力
- 舒适（5px）：标准卡片容器
- 宽松（6px）：导航、较大交互元素
- 大（8px）：特色卡片、英雄元素
- 复合：`0px 0px 6px 6px` 用于底部圆角容器（标签面板、下拉页脚）

## 6. 深度与 Elevations

| 级别 | 处理 | 用途 |
|-------|-----------|-----|
| 平面（Level 0） | 无阴影 | 页面背景、内联文本 |
| 环境光（Level 1） | `rgba(23,23,23,0.06) 0px 3px 6px` | 微妙卡片抬升、悬停提示 |
| 标准（Level 2） | `rgba(23,23,23,0.08) 0px 15px 35px` | 标准卡片、内容面板 |
| 提升（Level 3） | `rgba(50,50,93,0.25) 0px 30px 45px -30px, rgba(0,0,0,0.1) 0px 18px 36px -18px` | 特色卡片、下拉菜单、弹出框 |
| 深度（Level 4） | `rgba(3,3,39,0.25) 0px 14px 21px -14px, rgba(0,0,0,0.1) 0px 8px 17px -8px` | 模态框、浮动面板 |
| 环（无障碍） | `2px solid #533afd` 外框 | 键盘焦点环 |

**阴影哲学**：Stripe 的阴影系统建立在色彩深度原则之上。当大多数设计系统使用中性灰色或黑色阴影时，Stripe 的主阴影色 (`rgba(50,50,93,0.25)`) 是一种深蓝色，呼应品牌的海军蓝调色板。这创造出不仅增加深度、更增添品牌氛围的阴影。多层方法将这种蓝色调阴影与纯黑第二层 (`rgba(0,0,0,0.1)`) 在不同偏移量下配对，创造出视差般的深度感——品牌阴影离元素更远，中性阴影更近。负扩展值（-30px、-18px）确保阴影在水平方向上不超出元素的足迹，使 Elevations 保持垂直和受控。

### 装饰深度
- 深色品牌区块 (`#1c1e54`) 通过背景色对比创造沉浸式深度
- 英雄装饰使用红宝石色到洋红色过渡的渐变叠加
- 粘性元素的边缘阴影使用阴影色 `rgba(0,55,112,0.08)` (`--hds-color-shadow-sm-top`)

## 7. 宜与忌

### 宜
- 在所有文本元素上使用带 `"ss01"` 的 sohne-var——风格集就是品牌
- 所有标题和正文使用 300 字重——轻盈是标志性特征
- 所有提升元素使用蓝色调阴影 (`rgba(50,50,93,0.25)`)
- 标题使用 `#061b31`（深海军蓝）而非 `#000000`——温暖感很重要
- 圆角半径保持在 4px-8px 之间——保守圆角是有意为之
- 任何表格/金融数字展示使用 `"tnum"`
- 分层阴影：蓝色调远层 + 中性近层实现深度视差
- 使用 `#533afd` 紫色作为主交互/CTA 色

### 忌
- sohne-var 标题不要使用 600-700 字重——300 字重是品牌声音
- 卡片或按钮不要使用大圆角（12px+、药丸形状）——Stripe 是保守的
- 不要使用中性灰色阴影——始终使用蓝色调 (`rgba(50,50,93,...)`)
- 任何 sohne-var 文本不要跳过 `"ss01"`——替代字形定义个性
- 标题不要使用纯黑 (`#000000`)——始终使用 `#061b31` 深海军蓝
- 交互元素不要使用暖色强调色（橙色、黄色）——紫色是主色
- 大标题尺寸下不要应用正字距——Stripe 字距紧凑
- 按钮或链接不要使用洋红/红宝石强调色——它们仅用于装饰/渐变

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动端 | <640px | 单列，缩小标题尺寸，堆叠卡片 |
| 平板 | 640-1024px | 2 列网格，适中内边距 |
| 桌面 | 1024-1280px | 完整布局，3 列功能网格 |
| 大桌面 | >1280px | 居中内容带宽裕边距 |

### 触摸目标
- 按钮使用舒适内边距（垂直 8px-16px）
- 导航链接 14px 带足够间距
- 徽章至少 6px 水平内边距作为点击目标
- 移动导航切换按钮带 6px 圆角

### 折叠策略
- 英雄区：56px 展示 -> 移动端 32px，保持 300 字重
- 导航：水平链接 + CTA -> 汉堡切换
- 功能卡片：3 列 -> 2 列 -> 单列堆叠
- 深色品牌区块：保持全宽处理，减小内边距
- 金融数据表格：移动端水平滚动
- 区块间距：64px+ -> 移动端 40px
- 排版比例压缩：跨断点 56px -> 48px -> 32px 英雄尺寸

### 图片行为
- 仪表板/产品截图在所有尺寸下保持蓝色调阴影
- 英雄渐变装饰在移动端简化
- 代码块保持 `SourceCodePro` 处理，可水平滚动
- 卡片图片保持 4px-6px 一致圆角

### 迭代指南
1. 始终在 sohne-var 文本上启用 `font-feature-settings: "ss01"`——这是品牌的排版 DNA
2. 300 字重是默认值；仅在按钮/链接/导航上使用 400
3. 阴影公式：`rgba(50,50,93,0.25) 0px Y1 B1 -S1, rgba(0,0,0,0.1) 0px Y2 B2 -S2`，其中 Y1/B1 较大（远阴影），Y2/B2 较小（近阴影）
4. 标题颜色为 `#061b31`（深海军蓝），正文为 `#64748d`（石板灰），标签为 `#273951`（深石板灰）
5. 圆角半径保持在 4px-8px 范围——切勿使用药丸形状或大圆角
6. 任何表格、图表或金融展示中的数字使用 `"tnum"`
7. 深色区块使用 `#1c1e54`——不是黑色，不是灰色，而是深品牌靛蓝
8. SourceCodePro 用于代码，12px/500 字重，2.00 行高（非常宽松以保证可读性）
