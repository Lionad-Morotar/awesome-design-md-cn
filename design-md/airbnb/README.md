# Airbnb 风格设计系统

[DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/airbnb/DESIGN.md) 提取自公开的 [airbnb](https://airbnb.com/) 网站。这不是官方设计系统。颜色、字体和间距可能并非 100% 准确，但它是构建类似项目的一个良好起点。

## 文件

| 文件 | 说明 |
|------|------|
| `DESIGN.md` | 完整的设计系统文档（9 个章节） |
| `preview.html` | 交互式设计令牌目录（浅色） |
| `preview-dark.html` | 交互式设计令牌目录（深色） |

使用 [DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/airbnb/DESIGN.md) 作为 AI 智能体（Claude、Cursor、Stitch）的参考，以生成符合 Airbnb 设计语言的 UI。

## 预览
