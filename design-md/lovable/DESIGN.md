# 设计系统：Lovable

## 1. 视觉主题与氛围

Lovable 的网站通过克制散发出温暖。整个页面停留在奶油色、羊皮纸色调的背景（`#f7f4ed`）上，立即使其与大多数开发者工具网站的冷白色惯例区分开来。这不是为了极简主义而极简主义——这是一个深思熟虑的选择，让人感觉平易近人，几乎是模拟的，就像一本精心制作的笔记本。这种温暖的奶油色背景上的近黑色文本（`#1c1c1c`）创造了对比度，对眼睛很舒适，同时保持了清晰的可读性。

自定义的 Camera Plain Variable 字体是该系统的秘密武器。与标志"科技公司"的几何无衬线字体不同，Camera Plain 拥有人文主义的温暖——略微圆润的终端、有机的曲线和舒适的阅读节奏。在展示尺寸（48px–60px）下，字重 600 配合激进的负字间距（-0.9px 至 -1.5px）将标题压缩成自信、编辑化的陈述。该字体使用 `ui-sans-serif, system-ui` 作为回退方案，承认自定义字体承载着品牌个性。

Lovable 视觉系统的独特之处在于其不透明度驱动的深度模型。该系统不是使用传统的灰色调，而是调制 `#1c1c1c` 在不同不透明度下（0.03、0.04、0.4、0.82–0.83）来创建统一的色调范围。页面上的每一种灰色在技术上都是相同的色调——只是透明度更高或更低。这创造了一种视觉连贯性，几乎不可能用任意的十六进制值实现。边框系统也是如此：`1px solid #eceae4` 用于浅色分隔，`1px solid rgba(28, 28, 28, 0.4)` 用于更强的交互边界。

**关键特征：**
- 温暖的羊皮纸背景（`#f7f4ed`）——不是白色，不是米色，是一种精心选择的奶油色，感觉手工挑选
- Camera Plain Variable 字体，具有人文主义温暖，在展示尺寸下采用编辑化的字间距
- 不透明度驱动的色彩系统：所有灰色均派生自不同透明度级别的 `#1c1c1c`
- 按钮上的内阴影技术：`rgba(255,255,255,0.2) 0px 0.5px 0px 0px inset, rgba(0,0,0,0.2) 0px 0px 0px 0.5px inset`
- 温暖的中性边框调色板：`#eceae4` 用于微妙的边框，`rgba(28,28,28,0.4)` 用于交互元素
- 完整的药丸半径（`9999px`）广泛用于操作按钮和图标容器
- 焦点状态使用 `rgba(0,0,0,0.1) 0px 4px 12px` 阴影，呈现柔和、温暖的强调效果
- shadcn/ui + Radix UI 组件原语，配合 Tailwind CSS 实用工具样式

## 2. 色彩调色板与角色

### 主色
- **奶油色**（`#f7f4ed`）：页面背景、卡片表面、按钮表面。基础——温暖、纸质感、人性化。
- **炭黑色**（`#1c1c1c`）：主要文本、标题、深色按钮背景。不是纯黑色——有机的温暖。
- **灰白色**（`#fcfbf8`）：深色背景上的按钮文本、微妙的高光。与纯白色几乎无法区分。

### 中性色阶（基于不透明度）
- **炭黑色 100%**（`#1c1c1c`）：主要文本、标题、深色表面。
- **炭黑色 83%**（`rgba(28,28,28,0.83)`）：强烈的次要文本。
- **炭黑色 82%**（`rgba(28,28,28,0.82)`）：正文副本。
- **柔和灰**（`#5f5f5d`）：次要文本、描述、标题说明。
- **炭黑色 40%**（`rgba(28,28,28,0.4)`）：交互边框、按钮轮廓。
- **炭黑色 4%**（`rgba(28,28,28,0.04)`）：微妙的悬停背景、微色调。
- **炭黑色 3%**（`rgba(28,28,28,0.03)`）：几乎不可见的叠加层、背景深度。

### 表面与边框
- **浅奶油色**（`#eceae4`）：卡片边框、分隔线、图像轮廓。温暖的分隔线。
- **奶油色表面**（`#f7f4ed`）：卡片背景、区域填充——与页面背景相同，实现无缝集成。

### 交互
- **环形蓝**（`#3b82f6` 50% 不透明度）：`--tw-ring-color`，Tailwind 焦点环。
- **焦点阴影**（`rgba(0,0,0,0.1) 0px 4px 12px`）：焦点和激活状态阴影——柔和、温暖、漫射。

### 内阴影
- **按钮内阴影**（`rgba(255,255,255,0.2) 0px 0.5px 0px 0px inset, rgba(0,0,0,0.2) 0px 0px 0px 0.5px inset, rgba(0,0,0,0.05) 0px 1px 2px 0px`）：深色按钮上的标志性多层内阴影。

## 3. 排版规则

### 字体系列
- **主要**：`Camera Plain Variable`，回退方案：`ui-sans-serif, system-ui`
- **字重范围**：400（正文/阅读）、480（特殊展示）、600（标题/强调）
- **特性**：可变字体，具有连续的字重轴——允许微调中间字重，如 480。

### 层次结构

### 原则
- **温暖的人文主义声音**：Camera Plain Variable 赋予 Lovable 平易近人的个性。略微圆润的终端和有机的曲线与大多数开发者工具使用的尖锐几何无衬线字体形成对比。
- **可变字重作为设计工具**：该字体支持连续字重值（例如 480），能够超越标准字重停止点进行微妙的层次结构划分。60px 下的字重 480 创造出一种展示风格，感觉比半粗体轻但比常规字体强。
- **按比例压缩**：标题使用负字间距（-0.9px 至 -1.5px）以产生编辑冲击力。正文字体保持正常追踪以舒适阅读。
- **两个字重，明确角色**：400（正文/UI/链接/按钮）和 600（标题/强调）。狭窄的字重范围通过尺寸和间距创造层次结构，而非字重变化。

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 比例：8px、10px、12px、16px、24px、32px、40px、56px、80px、96px、128px、176px、192px、208px
- 该比例在高端 generously 扩展——区域使用 80px–208px 垂直间距以获得编辑呼吸空间

### 网格与容器
- 最大内容宽度：约 1200px（居中）
- 英雄：居中单列，巨大的垂直内边距（96px+）
- 功能区：2–3 列网格
- 全宽页脚，多列链接布局
- 展示区域，居中卡片网格

### 空白哲学
- **编辑慷慨性**：Lovable 的间距在区域边界处丰富（80px–208px）。温暖的奶油色背景使这些广阔区域感觉舒适而非空旷。
- **内容驱动的韵律**：卡片内部的紧密间距（12–24px）与宽阔的区域间隙形成对比，创造出一种阅读节奏，在专注内容和视觉休息之间交替。
- **区域分隔**：页脚使用 `1px solid #eceae4` 边框和 16px 半径容器。区域通过 generous 间距而非边框线定义。

### 边框半径比例
- 微型（4px）：小按钮、交互元素
- 标准（6px）：按钮、输入、导航菜单
- 舒适（8px）：紧凑卡片、分隔
- 卡片（12px）：标准卡片、图片容器、模板
- 容器（16px）：大容器、页脚区域
- 完整药丸（9999px）：操作药丸、图标按钮、切换开关

## 6. 深度与高程

| 级别 | 处理 | 用途 |
|-------|-----------|-----|
| 平面（级别 0） | 无阴影，奶油色背景 | 页面表面、大多数内容 |
| 边框（级别 1） | `1px solid #eceae4` | 卡片、图片、分隔线 |
| 内嵌（级别 2） | `rgba(255,255,255,0.2) 0px 0.5px 0px inset, rgba(0,0,0,0.2) 0px 0px 0px 0.5px inset, rgba(0,0,0,0.05) 0px 1px 2px` | 深色按钮、主要操作 |
| 焦点（级别 3） | `rgba(0,0,0,0.1) 0px 4px 12px` | 激活/焦点状态 |
| 环形（辅助功能） | `rgba(59,130,246,0.5)` 2px 环 | 输入上的键盘焦点 |

**阴影哲学**：Lovable 的深度系统有意浅显。该系统不依赖带有戏剧性投影的悬浮卡片，而是依靠奶油色表面上的温暖边框（`#eceae4`）来创造温柔的包容感。唯一值得注意的阴影图案是深色按钮上的内阴影——一种微妙的多层技术，其中白色高光线条位于顶部边缘，而深色环和柔和底部处理底部。这创造了一种压入表面的触感，而非悬浮在表面之上的感觉。温暖的焦点阴影（`rgba(0,0,0,0.1) 0px 4px 12px`）有意漫射且大，创造柔和的光晕而非尖锐的轮廓。

### 装饰深度
- 英雄：柔和、温暖的多色渐变洗刷（粉色、橙色、蓝色）在英雄内容后面——大气、几乎不可见
- 页脚：渐变背景，暖色调过渡到底部
- 无生硬的区域分隔——间距和背景温暖处理过渡

## 7. 宜与忌

### 宜
- 使用温暖的奶油色背景（`#f7f4ed`）作为页面基础——这是品牌的标志性温暖
- 在展示尺寸下使用 Camera Plain Variable，配合负字间距（-0.9px 至 -1.5px）
- 从 `#1c1c1c` 派生所有灰色，在不同不透明度级别下实现色调统一
- 在深色按钮上使用内阴影技术以获得触感深度
- 使用 `#eceae4` 边框而非阴影进行卡片包容
- 保持狭窄的字重系统：400 用于正文/UI，600 用于标题
- 仅对操作药丸和图标按钮使用完整药丸半径（9999px）
- 在激活状态下应用不透明度 0.8 以获得响应式触感反馈

### 忌
- 不要使用纯白色（`#ffffff`）作为页面背景——奶油色是有意的
- 不要对卡片使用重的盒状阴影——边框是包容机制
- 不要引入饱和的强调色——调色板有意温暖中性
- 不要使用字重 700（粗体）——600 是系统中的最大字重
- 不要在矩形按钮上应用 9999px 半径——药丸用于图标/操作切换
- 不要使用尖锐的焦点轮廓——系统使用柔和的基于阴影的焦点指示器
- 不要混合边框样式——`#eceae4` 用于被动的，`rgba(28,28,28,0.4)` 用于交互的
- 不要在标题上增加字间距——Camera Plain 旨在在大规模下紧凑运行

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 小手机 | <600px | 紧密单列，减少内边距 |
| 手机 | 600–640px | 标准移动布局 |
| 小平板 | 640–700px | 2 列网格开始 |
| 平板 | 700–768px | 卡片网格扩展 |
| 小桌面 | 768–1024px | 多列布局 |
| 桌面 | 1024–1280px | 完整功能布局 |
| 大桌面 | 1280–1536px | 最大内容宽度，慷慨边距 |

### 触摸目标
- 按钮：8px 16px 内边距（舒适触摸）
- 导航：项目之间充足的间距
- 药丸按钮：9999px 半径创造大点击友好目标
- 菜单切换：6px 半径按钮，尺寸充足

### 折叠策略
- 英雄：60px → 48px → 36px 标题缩放，配合比例字间距
- 导航：水平链接 → 768px 时汉堡菜单
- 功能卡片：3 列 → 2 列 → 单列堆叠
- 模板画廊：网格 → 堆叠垂直卡片
- 统计数据栏：水平 → 堆叠垂直
- 页脚：多列 → 堆叠单列
- 区域间距：128px+ → 移动端 64px

### 图片行为
- 模板截图在所有尺寸下保持 `1px solid #eceae4` 边框
- 12px 边框半径在所有断点下保持不变
- 画廊图片响应式，一致的宽高比
- 英雄渐变在移动端简化/柔和

### 迭代指南
1. 始终使用奶油色（`#f7f4ed`）作为基础——永不使用纯白色
2. 从 `#1c1c1c` 派生灰色，在不透明度级别下而非使用不同的十六进制值
3. 使用 `#eceae4` 边框进行包容，而非阴影
4. 字间距随尺寸缩放：60px 时 -1.5px，48px 时 -1.2px，36px 时 -0.9px，16px 时 normal
5. 两个字重：400（除标题外的一切）和 600（标题）
6. 深色按钮上的内阴影是标志性细节——不要跳过它
7. Camera Plain Variable 字重 480 仅用于特殊展示时刻
