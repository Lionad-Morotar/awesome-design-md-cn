# 设计系统：NVIDIA

## 1. 视觉主题与氛围

NVIDIA 的网站是一个高对比度、技术导向的体验，通过设计克制传达原始的计算能力。页面构建在鲜明的黑 (`#000000`) 白 (`#ffffff`) 基础之上，并以 NVIDIA 标志性的绿色 (`#76b900`) 作为点缀——这种颜色非常特定，堪称品牌的指纹。这不是大自然中郁郁葱葱的绿色；而是 GPU 渲染出的电光般的石灰绿，一种介于黄绿色和翠绿色之间的颜色，对任何懂技术的人来说都立即意味着"NVIDIA"。

定制的 NVIDIA-EMEA 字体系列（带有 Arial 和 Helvetica 后备）创造了干净、工业化的排版风格。36px 粗体、1.25 紧凑行高的标题创建了密集而权威的文本块。这种字体没有硅谷无衬线字体的几何趣味性——它是欧洲的、实用主义的、以工程为中心的。正文文本运行在 15-16px，阅读舒适但并不宽裕，保持着屏幕空间像 GPU 内存一样被优化的感觉。

NVIDIA 的设计与其他深色背景科技网站的区别在于对绿色点缀的克制使用。`#76b900` 出现在边框（`2px solid #76b900`）、链接下划线（`underline 2px rgb(118, 185, 0)`）和 CTA 按钮上——但从不作为背景或大面积表面出现在主内容上。绿色是信号，不是表面。结合深度阴影系统（`rgba(0, 0, 0, 0.3) 0px 0px 5px`）和最小边框半径（1-2px），整体效果是以像素渲染的精密工程硬件。

**关键特征：**
- NVIDIA 绿 (`#76b900`) 作为纯点缀——仅用于边框、下划线和交互高亮
- 黑色 (`#000000`) 主导背景，深色区域配白色 (`#ffffff`) 文本
- NVIDIA-EMEA 定制字体，Arial/Helvetica 后备——工业化、欧式、干净
- 紧凑的行高（标题 1.25）创建密集、权威的文本块
- 最小边框半径（1-2px）——全程保持锋利、工程化的边角
- 绿色边框按钮（`2px solid #76b900`）作为主要交互模式
- Font Awesome 6 Pro/Sharp 图标系统，900 粗重用于锋利图标
- 多框架架构（PrimeReact、Fluent UI、Element Plus）支持丰富的交互组件

## 2. 色板与角色

### 主品牌色
- **NVIDIA 绿** (`#76b900`): 标志性色彩——边框、链接下划线、CTA 轮廓、激活指示器。从不用作大表面填充。
- **纯黑** (`#000000`): 主页面背景，浅色表面上的文本，主导色调。
- **纯白** (`#ffffff`): 深色背景上的文本，浅色区域背景，卡片表面。

### 扩展品牌色板
- **NVIDIA 绿浅** (`#bff230`): 亮柠檬点缀，用于高亮和悬停状态。
- **橙 400** (`#df6500`): 用于警告、精选徽章或能源相关上下文的暖色点缀。
- **黄 300** (`#ef9100`): 次要暖色点缀，产品类别高亮。
- **黄 050** (`#feeeb2`): 浅色暖色表面，用于标注背景。

### 状态与语义色
- **红 500** (`#e52020`): 错误状态，破坏性操作，关键警告。
- **红 800** (`#650b0b`): 深红用于严重警告背景。
- **绿 500** (`#3f8500`): 成功状态，正面指示器（比品牌绿更深）。
- **蓝 700** (`#0046a4`): 信息性点缀，链接悬停替代色。

### 装饰色
- **紫 800** (`#4d1368`): 深紫用于渐变终点、高级/AI 上下文。
- **紫 100** (`#f9d4ff`): 浅紫色表面色调。
- **洋红 700** (`#8c1c55`): 丰富的点缀，用于特别促销或精选内容。

### 中性色阶
- **灰 300** (`#a7a7a7`): 柔和文本，禁用标签。
- **灰 400** (`#898989`): 次要文本，元数据。
- **灰 500** (`#757575`): 三级文本，占位符，页脚。
- **灰边框** (`#5e5e5e`): 微妙的边框，分隔线。
- **近黑** (`#1a1a1a`): 深色表面，黑色页面上的卡片背景。

### 交互状态
- **链接默认 (深色背景)** (`#ffffff`): 深色背景上的白色链接。
- **链接默认 (浅色背景)** (`#000000`): 浅色背景上带绿色下划线的黑色链接。
- **链接悬停** (`#3860be`): 所有链接变体悬停时偏蓝。
- **按钮悬停** (`#1eaedb`): 青色高亮用于按钮悬停状态。
- **按钮激活** (`#007fff`): 亮蓝用于激活/按下按钮状态。
- **焦点环** (`#000000 solid 2px`): 键盘焦点的黑色轮廓。

### 阴影与深度
- **卡片阴影** (`rgba(0, 0, 0, 0.3) 0px 0px 5px 0px`): 用于悬浮卡片的微妙环境阴影。

### 原则
- **粗体作为默认声音**: NVIDIA 大量依赖 700 字重用于标题、按钮、链接和标签。400 字重保留给正文文本和描述——其他所有内容都是粗体，传达自信和权威。
- **紧凑标题，宽松正文**: 标题行高始终为 1.25（紧凑），而正文文本放松到 1.50-1.67。这种对比在内容块顶部创建视觉密度，在段落中保持舒适的阅读体验。
- **导航用大写**: 链接标签使用 `text-transform: uppercase` 配 700 字重，创建读起来像硬件规格标签的导航声音。
- **无装饰性字距**: 字间距全程正常，除了紧凑按钮 (0.144px)。字体本身承载工业特征，无需操纵。

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 比例尺：1px, 2px, 3px, 4px, 5px, 6px, 7px, 8px, 9px, 10px, 11px, 12px, 13px, 15px
- 主要内边距值：8px, 11px, 13px, 16px, 24px, 32px
- 区域间距：48-80px 垂直内边距

### 网格与容器
- 最大内容宽度：约 1200px（受限）
- 全宽主区域配受限文本
- 功能区域：2-3 列网格用于产品卡片
- 文章/博客内容的单列
- 文档的侧边栏布局

### 留白哲学
- **有目的的密度**: NVIDIA 使用比典型 SaaS 网站更紧凑的间距，反映技术内容的密度。留白用于分离概念，而非创造奢华的空虚。
- **区域节奏**: 深色区域与白色区域交替，使用背景色（而不仅是间距）来分隔内容块。
- **卡片密度**: 产品卡片以 16-20px 间隙紧密排列，创建目录感而非画廊感。

### 边框半径比例尺
- 微型 (1px): 内联跨度、微小元素
- 标准 (2px): 按钮、卡片、容器、输入——几乎一切的默认
- 圆形 (50%): 头像图像、圆形标签指示器

## 6. 深度与高程

| 级别 | 处理 | 用途 |
|------|------|------|
| 平面 (Level 0) | 无阴影 | 页面背景、内联文本 |
| 微妙 (Level 1) | `rgba(0,0,0,0.3) 0px 0px 5px 0px` | 标准卡片、模态框 |
| 边框 (Level 1b) | `1px solid #5e5e5e` | 内容分隔线、区域边框 |
| 绿色点缀 (Level 2) | `2px solid #76b900` | 激活元素、CTA、选中项 |
| 焦点 (无障碍) | `2px solid #000000` outline | 键盘焦点环 |

**阴影哲学**: NVIDIA 的深度系统最小且实用。本质上只有一个阴影值——30% 透明度下的 5px 环境模糊——零星用于卡片和模态框。主要的深度信号不是阴影而是_颜色对比_：黑色背景紧邻白色区域，黑色表面上的绿色边框。这创建了硬件般的视觉分层，深度来自材质差异，而非模拟光线。

### 装饰深度
- 主内容背后的绿色渐变洗色
- 深色到更深色（黑色到近黑色）的渐变用于区域过渡
- 无玻璃拟态或模糊效果——清晰度高于氛围

- 主图：36px 标题按比例缩小

- GPU/产品渲染在所有尺寸下保持高分辨率
- 主图随视口按比例缩放

- 全出血深色区域保持边缘到边缘处理

## 8. 响应式行为（扩展）

### 排版缩放
- 展示标题 36px 在移动端缩放到约 24px
- 区域标题 24px 在移动端缩放到约 20px
- 正文文本在所有断点保持 15-16px
- 按钮文本保持 16px 用于一致的点击目标

### 深色/浅色区域策略
- 深色区域（黑色背景，白色文本）与浅色区域（白色背景，黑色文本）交替
- 绿色点缀在两种表面类型上保持一致
- 在深色上：链接为白色，下划线为绿色
- 在浅色上：链接为黑色，下划线为绿色
- 这种交替创建自然的滚动节奏和内容分组

### 迭代指南
1. 始终使用 `#76b900` 作为点缀，从不用作背景填充——它是信号色，用于边框、下划线和高亮
2. 按钮默认是透明带绿色边框——填充背景仅在悬停/激活状态下出现
3. 700 字重是所有交互和标题元素的主导声音；400 仅用于正文段落
4. 边框半径对所有内容都是 2px——这种锋利、最小的圆角是工业化美学的核心
