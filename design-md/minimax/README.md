# Minimax 风格设计系统

[DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/minimax/DESIGN.md) 提取自公开的 [minimax](https://minimax.io/) 网站。这不是官方设计系统。颜色、字体和间距可能并非 100% 准确，但它是构建类似风格的良好起点。

## 文件

| 文件 | 说明 |
|------|------|
| `DESIGN.md` | 完整的设计系统文档（9 个章节） |
| `preview.html` | 交互式设计 Token 目录（浅色） |
| `preview-dark.html` | 交互式设计 Token 目录（深色） |


使用 [DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/minimax/DESIGN.md) 作为参考，供 AI 智能体（Claude、Cursor、Stitch）生成符合 Minimax 设计语言的 UI。
