# 设计系统：Pinterest

## 1. 视觉主题与氛围

Pinterest 的网站是一个温暖、以灵感为驱动的画布，将视觉发现视为一种生活方式杂志。设计运行在柔和、略带暖意的白色背景上，使用 Pinterest 红 (`#e60023`) 作为单一醒目的品牌强调色。与大多数科技平台的冷蓝色调不同，Pinterest 的中性色系具有明显的暖色调——灰色偏向橄榄/沙色 (`#91918c`, `#62625b`, `#e5e5e0`) 而非冷钢色，营造出一种舒适、手工般的氛围，邀请用户浏览。

排版使用 Pin Sans——一种定制的专有字体，具有包含日语字体的广泛回退栈，反映了 Pinterest 的全球覆盖范围。在展示尺度（70px，字重 600）下，Pin Sans 创造出大而醒目的标题。在较小尺寸下，系统紧凑：按钮为 12px，说明文字为 12-14px。CSS 变量命名系统（`--comp-*`、`--sema-*`、`--base-*`）揭示了一个复杂的三层设计令牌架构：组件级、语义级和基础级令牌。

Pinterest 的独特之处在于其宽松的圆角系统（12px-40px，加上 50% 用于圆形）和暖色调按钮背景。次要按钮 (`#e5e5e0`) 具有明显的暖沙色调而非冷灰色。主色红色按钮使用 16px 圆角——圆润但非胶囊形。结合温暖的徽章背景（`hsla(60,20%,98%,.5)`——微妙的黄色暖色调）和以摄影为主导的布局，呈现出一种手工打造和个人化的设计感，而非企业化和冰冷的感觉。

**关键特征：**
- 暖白色画布配橄榄/沙色调中性色——舒适，而非临床感
- Pinterest 红 (`#e60023`) 作为单一醒目强调色——从不微妙，总是自信
- Pin Sans 定制字体配全球回退栈（包括中日韩文字）
- 三层令牌架构：`--comp-*` / `--sema-*` / `--base-*`
- 温暖次要表面：沙灰 (`#e5e5e0`)，暖色徽章 (`hsla(60,20%,98%,.5)`)
- 宽松圆角：16px 标准，大容器最大 40px
- 以摄影为优先的内容——pin/图片是主要视觉元素
- 深紫黑色文本 (`#211922`)——温暖，带一丝梅子色调

## 2. 色彩调色板与角色

### 主品牌色
- **Pinterest 红** (`#e60023`): 主要 CTA、品牌强调色——大胆、自信的红
- **绿 700** (`#103c25`): `--base-color-green-700`，成功/自然强调色
- **绿 700 悬停** (`#0b2819`): `--base-color-hover-green-700`，按压绿色

### 文本色
- **梅子黑** (`#211922`): 主要文本——带梅子底色的暖近黑色
- **黑** (`#000000`): 次要文本、按钮文本
- **橄榄灰** (`#62625b`): 次要描述、弱化文本
- **暖银** (`#91918c`): `--comp-button-color-text-transparent-disabled`，禁用文本、输入框边框
- **白** (`#ffffff`): 深色/彩色表面上的文本

### 交互色
- **焦点蓝** (`#435ee5`): `--comp-button-color-border-focus-outer-transparent`，焦点环
- **性能紫** (`#6845ab`): `--sema-color-hover-icon-performance-plus`，性能特性
- **推荐紫** (`#7e238b`): `--sema-color-hover-text-recommendation`，AI 推荐
- **链接蓝** (`#2b48d4`): 链接文本色
- **Facebook 蓝** (`#0866ff`): `--facebook-background-color`，社交登录
- **按压蓝** (`#617bff`): `--base-color-pressed-blue-200`，按压状态

### 表面与边框
- **沙灰** (`#e5e5e0`): 次要按钮背景——温暖、手工感
- **暖浅** (`#e0e0d9`): 圆形按钮背景、徽章
- **暖洗** (`hsla(60, 20%, 98%, 0.5)`): `--comp-badge-color-background-wash-light`，微妙的暖色徽章背景
- **雾** (`#f6f6f3`): 浅色表面（50% 透明度）
- **边框禁用** (`#c8c8c1`): `--sema-color-border-disabled`，禁用边框
- **悬停灰** (`#bcbcb3`): `--base-color-hover-grayscale-150`，悬停边框
- **深色表面** (`#33332e`): 深色区块背景

### 语义色
- **错误红** (`#9e0a0a`): 复选框/表单错误状态

## 3. 排版规则

### 字体系列
- **主要**: `Pin Sans`，回退：`-apple-system, system-ui, Segoe UI, Roboto, Oxygen-Sans, Apple Color Emoji, Segoe UI Emoji, Segoe UI Symbol, Ubuntu, Cantarell, Fira Sans, Droid Sans, Helvetica Neue, Helvetica, ヒラギノ角ゴ Pro W3, メイリオ, Meiryo, M SP ゴシック，Arial`

### 层级

| 角色 | 字体 | 字号 | 字重 | 行高 | 字间距 | 备注 |
|------|------|------|--------|-------------|----------------|------|
| 展示主标题 | Pin Sans | 70px (4.38rem) | 600 | normal | normal | 最大影响力 |
| 区块标题 | Pin Sans | 28px (1.75rem) | 700 | normal | -1.2px | 负字间距 |
| 正文 | Pin Sans | 16px (1.00rem) | 400 | 1.40 | normal | 标准阅读 |
| 说明加粗 | Pin Sans | 14px (0.88rem) | 700 | normal | normal | 强调元数据 |
| 说明 | Pin Sans | 12px (0.75rem) | 400-500 | 1.50 | normal | 小文本、标签 |
| 按钮 | Pin Sans | 12px (0.75rem) | 400 | normal | normal | 按钮标签 |

### 原则
- **紧凑的字体比例**: 范围从 12px-70px，跨度巨大——大多数功能文本为 12-16px，形成密集的类应用信息层级
- **暖色字重分布**: 标题 600-700，正文 400-500。没有超细字重——字体始终感觉扎实
- **标题负字间距**: 28px 标题使用 -1.2px，营造舒适、亲密的区块标题
- **单一字体系列**: Pin Sans 处理一切——未检测到次要展示或等宽字体

## 4. 组件样式

### 按钮

**主红色按钮**
- 背景：`#e60023` (Pinterest 红)
- 文本：`#000000` (黑色——在红色上对比的不寻常选择)
- 内边距：6px 14px
- 圆角：16px (宽松圆润，非胶囊形)
- 边框：`2px solid rgba(255, 255, 255, 0)` (透明)
- 焦点：通过 CSS 变量的语义边框 + 轮廓

**次级沙色按钮**
- 背景：`#e5e5e0` (暖沙灰)
- 文本：`#000000`
- 内边距：6px 14px
- 圆角：16px
- 焦点：相同的语义边框系统

**圆形操作按钮**
- 背景：`#e0e0d9` (暖浅)
- 文本：`#211922` (梅子黑)
- 圆角：50% (圆形)
- 用途：Pin 操作、导航控制

**幽灵/透明按钮**
- 背景：透明
- 文本：`#000000`
- 无边框
- 用途：次要操作

### 卡片与容器
- 以摄影为优先的 pin 卡片， generous 圆角 (12px-20px)
- 大多数卡片无传统盒阴影
- 白色或暖雾背景
- 某些图像容器有 8px 白色粗边框

### 输入框
- 邮箱输入：白色背景，`1px solid #91918c` 边框，16px 圆角，11px 15px 内边距
- 焦点：通过 CSS 变量的语义边框 + 轮廓系统

### 导航
- 白色或暖色背景上的干净页眉
- Pinterest logo + 居中搜索栏
- Pin Sans 16px 用于导航链接
- Pinterest 红强调用于激活状态

### 图像处理
- Pin 风格砌体网格（Pinterest 标志性布局）
- 圆角：图像 12px-20px
- 摄影作为主要内容——每个 pin 都是图像
- 特色图像容器有粗白边框 (8px)

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 比例：4px, 6px, 7px, 8px, 10px, 11px, 12px, 16px, 18px, 20px, 22px, 24px, 32px, 80px, 100px
- 大跨度：32px → 80px → 100px 用于区块间距

### 网格与容器
- 用于 pin 内容的砌体网格（标志性布局）
- 居中的内容区块，宽松的最大宽度
- 全宽深色页脚
- 搜索栏作为主要导航元素

### 留白哲学
- **灵感密度**: 砌体网格紧密打包 pin——内容密度本身就是价值主张。留白存在于区块之间，而非网格内部
- **上方呼吸，下方密集**: 主图/特色区块获得 generous 内边距；pin 网格紧凑且沉浸

### 圆角比例尺
- 标准 (12px): 小卡片、链接
- 按钮 (16px): 按钮、输入框、中等卡片
- 舒适 (20px): 特色卡片
- 大 (28px): 大容器
- 区块 (32px): 标签元素、大面板
- 主图 (40px): 主图容器、大特色区块
- 圆形 (50%): 操作按钮、标签指示器

## 6. 深度与层次

| 级别 | 处理 | 用途 |
|-------|-----------|-----|
| 扁平 (Level 0) | 无阴影 | 默认——pin 依赖内容，而非阴影 |
| 微妙 (Level 1) | 最小阴影（来自令牌） | 提升覆盖层、下拉菜单 |
| 焦点 (无障碍) | `--sema-color-border-focus-outer-default` 环 | 焦点状态 |

**阴影哲学**: Pinterest 使用最少的阴影。砌体网格依赖内容（摄影）来创造视觉兴趣，而非提升效果。深度来自表面色彩的温暖和容器的 generous 圆角。

## 7. 做与不做

### 做
- 使用暖中性色 (`#e5e5e0`, `#e0e0d9`, `#91918c`)——暖橄榄/沙色调是身份标识
- 仅在主要 CTA 上使用 Pinterest 红 (`#e60023`)——它大胆且单一
- 专门使用 Pin Sans——一种字体用于一切
- 应用宽松圆角：按钮/输入框 16px，卡片 20px+
- 保持砌体网格密集——内容密度是价值所在
- 使用暖色徽章背景 (`hsla(60,20%,98%,.5)`) 用于微妙暖洗效果
- 使用 `#211922` (梅子黑) 作为主要文本——它比纯黑更温暖

### 不做
- 不要使用冷灰中性色——始终使用暖/橄榄色调
- 不要使用纯黑 (`#000000`) 作为主要文本——使用梅子黑 (`#211922`)
- 不要使用胶囊形按钮——16px 圆角是圆润但非胶囊
- 不要添加厚重阴影——Pinterest 按设计是扁平的，深度来自内容
- 不要在卡片上使用小圆角 (<12px)——generous 圆角是核心
- 不要引入额外的品牌色——红 + 暖中性色是完整调色板
- 不要使用细字重——Pin Sans 最低 400

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动端 | <576px | 单列，紧凑布局 |
| 大移动端 | 576-768px | 2 列 pin 网格 |
| 平板 | 768-890px | 扩展网格 |
| 小桌面 | 890-1312px | 标准砌体网格 |
| 桌面 | 1312-1440px | 完整布局 |
| 大桌面 | 1440-1680px | 扩展网格列 |
| 超宽屏 | >1680px | 最大网格密度 |

### 折叠策略
- Pin 网格：5+ 列 → 3 → 2 → 1
- 导航：搜索栏 + 图标 → 简化移动端导航
- 特色区块：并排 → 堆叠
- 主图：70px → 按比例缩小
- 页脚：深色多列 → 堆叠

### 快速颜色参考

- 背景：白 (`#ffffff`)
- 文本：梅子黑 (`#211922`)
- 次要文本：橄榄灰 (`#62625b`)
- 按钮表面：沙灰 (`#e5e5e0`)

### 示例组件提示词
- "创建一个主图：白色背景。标题 70px Pin Sans 字重 600，梅子黑 (#211922)。红色 CTA 按钮 (#e60023, 16px 圆角，6px 14px 内边距)。次要沙色按钮 (#e5e5e0, 16px 圆角)。"
- "设计一个 pin 卡片：白色背景，16px 圆角，无阴影。摄影填充顶部，下方 16px Pin Sans 字重 400 描述，颜色 #62625b。"

- "设计深色页脚：#33332e 背景。白色 Pinterest script logo。12px Pin Sans 链接，颜色 #91918c。"

### 迭代指南
1. 到处使用暖中性色——橄榄/沙灰，而非冷钢
2. Pinterest 红仅用于 CTA——大胆且单一
3. 按钮/输入框 16px 圆角，卡片 20px+—— generous 但非胶囊
4. Pin Sans 是唯一字体——UI 紧凑 12px，展示 70px
5. 摄影承载设计——UI 保持温暖和极简
6. 文本使用梅子黑 (#211922)——比纯黑更温暖
